# ============================================================
# リズムのパターンを、ファイルで作って、まとめて送るサンプル
#
#   使い方（tools/midi_bridge.py を動かしている画面で）:
#       !load example_patterns.txt
#   このファイルの、空行と「#」で始まる行以外が、1行ずつ ESP32 に送られます。
#   送ったあとは、DRUM 11 / BACKING 11 で選べます（電源を切っても残ります）。
#   ※ 11〜20 は「自分のパターン」の置き場です。すでに入っている内容は、上書きされます。
#   ※ ESP32 を STOP してから送るのがおすすめです（再生中でも使えます）。
# ============================================================

# ---- ドラム11: 「8ビート」をもとに、キックを変えた自分のパターン ----
DRUM COPY 2 11
DRUM NAME 11 マイ・ビート
#                  1...2...3...4...
DRUM SET 11 K      x.....x.x...x...
DRUM SET 11 S      ....x.......x...
DRUM SET 11 H      x.x.x.x.x.x.x.x.

# ---- バッキング11: 2拍ごとに和音をのばす、ゆっくりめ ----
BACKING SET 11     C-------C-------
BACKING NAME 11    ゆったり

# ---- 選ぶ ----
GROOVE 11 11
