コード進行マシン　操作・リズム編集

「操作」で、BPM・キー・パターンをその場で変えられます。「作る」で、マス目をクリックして新しいパターンを作れます（文字を打つ必要はありません。1マス = 16分音符、4マス = 1拍）。作ったドラム・バッキング・進行には、名前をつけて、ゲームに送れます（「ゲームに送る」）。

コードの駒（Ⅰ・Ⅴ7 など）を、順番に選ぶと、ゲームの「固有進行」の技になります。ゲームの盤に、この順番で並べると決まります（「→」は、とばして数えます）。キーが違っても、度数（Ⅰ・Ⅴ など）で決まります。

ライブ編集 ON

ライブ編集が ON のとき、最初の1回は、保存先に作って選びます（上書きの確認が出ることがあります）。そのあとは、変えたところだけを送ります。再生中に編集すると、次のマスから音が変わります。OFF のときは、「ESP32 に送る」を押すまで反映されません。

ゲームに送る

    

      
      
      
    

    

    
名前をつけて送ると、ゲームの「♪」のメニュー（ドラム・バッキング）や、図鑑（進行）に、すぐ増えます。ゲームを開いたままでも届きます。同じ名前で送り直すと、上書きされます。ESP32 には送りません。

    
ゲームに入っているもの

    


    
全部の端末の、公開ページのゲームへ、自動で送る（リアルタイム）

    
ここで「ゲームに送る」と、公開ページ（インターネット）のゲームを開いている全部の端末（パソコン・スマホ）に、すぐ届きます。リンクを一つずつ送る必要は、ありません。Google の Firebase（無料枠）に、ライブラリを書きこむ形です。最初の設定だけ、手順（docs/cloud_setup.md）のとおりに、Firebase の画面で行います。書きこめるのは、この Mac のブリッジだけ（秘密のキーは、この Mac の中にだけ保存されて、画面・ゲーム・GitHub には、出ません）。

Firebase の「プロジェクトの設定 → サービス アカウント」に「データベースのシークレット」が見つかるときだけ使えます（新しいプロジェクトでは、見つからないことがあります。そのときは、上の JSON ファイルを使ってください）。

      

    

    

      
      
    

    

    
つないだあと: ゲームの game/cloud.json の url に、上と同じ URL を書いて、GitHub Desktop でコミット・プッシュすると、公開ページが、この URL から受け取るようになります（URL は、公開されて、かまいません。秘密のキーは、書かないでください）。


    
公開ページ（インターネット）のゲームに、リンクかファイルで渡す

    
自動で送る設定を、していないときや、特定の端末にだけ渡したいときは、リンクかファイルで渡します。上の「ゲームに入っているもの」のうち、左のチェックが入っているものが、渡る対象です。リンクを開くと、ゲームが「取り込みますか?」と出します（取り込んだものは、そのブラウザに保存されます。スマホにも、リンクを送れば入ります）。リンクの内容は、ブラウザの中だけで作られ、どこにも送信されません。
