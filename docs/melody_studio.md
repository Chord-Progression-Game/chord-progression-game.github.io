# メロディをつける・書く（♪ メロディ）

- 作成: 2026-11-18（第5弾のご依頼）／ 対象: フリープレイ ／ 実装: `game/js/core/automelody.js`（自動でつける）・`game/js/game/usermelody.js`（音の編集・元に戻す）・`game/js/ui/melodystudio.js`（画面）・`game/js/game/presets.js`（コードとメロディのプリセット）
- 読む人: あなた（ゼミ・学内発表で説明するときの資料にも使えます）
- 流れるメロディにコードをつける「合わせる」（[melody_mode.md](melody_mode.md)）とは**逆向き**です。こちらは「**コードに、メロディをつける**」。

## 1. できること

| # | ご依頼 | できたこと |
|---|---|---|
| 1 | 出来上がったコード進行に、自動で、適切でセンスのあるメロディ（テンションは 9th まで）をつける | 「自動でメロディをつける」。作風を3つから選べる。「別の案にする」で、何通りでも。**元に戻す**で、前のメロディに戻せる |
| 2 | 出来上がったメロディを編集できる画面 | 自動でつけた音を、**ピアノロール**の上で、動かす・長さを変える・消す・足す |
| 3 | 1からメロディをつけられる DTM のような画面 | 同じ画面。メロディが空のところから、クリックで音を置いて書く。音の色と説明で、和音に合っているか分かる |
| 4 | それらメロディとコードを、プリセットとして保存 | 「☆ プリセット」と、画面の「コードとメロディをプリセットに保存」。**呼び出すと、駒とメロディが、いっしょに置かれる** |

## 2. 使い方

1. 上のバーの **「♪ メロディ」**（フリープレイだけ。チュートリアル・チャレンジ・「合わせる」では隠れる）を押す。
2. 画面の上に、盤の和音（1〜8番）が並ぶ。**和音は、ここでは変えない**（盤で並べてから開く。開いたまま、実機の盤を動かしても、反映される）。
3. 「**自動でメロディをつける**」を押す。気に入らなければ「**別の案にする**」（何度でも）。「**↶ 戻す**」で前の案に戻れる。
4. 音をクリックすると、その音が、いまの和音に**どう聞こえるか**の説明が、下に出る。ドラッグで動かし、右はしで長さを変える。
5. 「**コードとメロディをプリセットに保存**」で、名前をつけて残す。
6. 閉じるとき: 「閉じる」・Esc（音を選んでいるときは、1回目で選びをやめる）。

## 3. 画面の読み方

| 場所 | 意味 |
|---|---|
| 上の8つの枠 | 盤の和音（番号つき）。色は駒の働き（黄 = 安定・青 = 広がり・赤 = 緊張）。右上の ◎ ○ △ × は、そのステップのメロディが、和音に合っているか |
| 背景の色のついた行 | **緑 = その和音のコードの音 / 水色 = 9th**。ここに音を置くと、きれいに合う。左の鍵盤に合わせて、高さが分かる（ド の行に「ド5」などの印） |
| 縦線 | 太い線 = ステップの境目（2拍ごと）/ 中くらい = 拍 / 細い線 = 16分音符のマス |
| 音の色 | **緑 = コードの音 / 水色 = テンション / 灰 = 経過音 / 黄 = 不安定 / 赤 = アヴォイド**（「合わせる」のメロディの帯と同じ） |
| 黄色い縦線 | いまの再生位置（演奏中だけ） |

## 4. 操作

| 操作 | 動き |
|---|---|
| 空いているところをクリック | 音を置く（長さは「音の長さ」で選んだもの。16分・8分・4分・2分）。置いてすぐドラッグすると、長さがのびる |
| 音をドラッグ | 動かす（横 = 時間・縦 = 高さ。時間は「音の長さ」の単位にそろう） |
| 音の右はしをドラッグ | 長さを変える |
| 右クリック / Delete | 音を消す |
| 矢印キー | 選んだ音を、← → で時間（音の長さの単位）・↑ ↓ で半音（Shift で1オクターブ） |
| Ctrl/⌘ + Z / Shift + Z | 元に戻す / やり直す（100回まで） |
| 左の鍵盤をクリック | その音が鳴る |
| Space | 演奏の ON/OFF |
| 「メロディの音 ON/OFF」 | メロディを鳴らすか（フリープレイの演奏に反映。保存される） |

- 同じ高さの音が重なったときは、**あとから置いた（動かした）音が優先**で、前の音が短くなる（消えることもある）。違う高さなら、重ねられる（和音のように）。
- 音は 160 個まで。高さは C3〜C7。1周 = 8ステップ = 64マス（16分音符）。

## 5. 自動でメロディをつけるルール

**ルールで作ります**（学習モデルではない）。**同じ種（seed）なら、いつも同じメロディ**です。つくる手順:

1. **リズム**: 1ステップ（2拍）ごとの「型」を選んで、フレーズの形に並べる。1小節目 = A（問い）/ 2小節目 = A の頭 + ちがう後ろ（答え）/ 3小節目 = B（対比）/ 4小節目 = 終わり（最後の音を長くのばす）。※「小節」= 2つのステップ。
2. **音の高さ**: 流れの形（山・波・下り・上り・高原）の目標に近づけながら、音を1つずつ選ぶ。
3. **360 通りつくって、いちばん良いものを採る**（できばえの点。下の表）。

### 5-1. 音の選び方（決まり）

| 決まり | 内容 | 理由 |
|---|---|---|
| **強い拍・長い音** | **コードの音と 9th だけ**（拍の頭・拍の頭から始まる音・長さ3マス以上の音） | メロディが和音とぶつからない（アヴォイドを避ける） |
| **テンションは 9th まで** | 11th・13th・♭9・♯9・♭13 は使わない。**9th も、使えるところだけ**: 調の音階の中にある 9th（Ⅰ の レ・Ⅳ の ソ・Ⅱm7 の ミ・Ⅵm7 の シ など）か、ドミナント7th の 9th（Ⅲ7 の ファ♯ など）。**Ⅲm7・Ⅶm7♭5・Ⅱ♭M7・dim7 などには、使わない**（音階の外の 9th は、濁るため） | ご指定「テンションは 9th まで」の解釈（下の 8章） |
| **9th の数** | 1つのメロディに、最大 4つ。フレーズの終わり（4番・8番の最後）には使わない | 9th は「色づけ」。使いすぎない・終わりは安定した音で |
| **短くて弱い拍の音** | 音階の**経過音**（上と下の音を、順にうめる）か**刺繍音**（となりの音へ行って戻る）。**ただし、11th・13th・7th（3和音の上）に聞こえる音は、経過音にも使わない**。置ける音がなければ、前の音をくり返す（8分の連打）か、のばす | メロディの帯が「水色 = テンション」と表示する音は、9th だけにする |
| **動き方** | 2度の順次進行が中心。5度以上の跳躍のあとは、反対へ戻る。跳躍は 9半音まで。同じ音を3回続けない | 歌いやすさ |
| **和音が変わるところ** | 共通音（同じ音のまま）を好む。7th は下の音へ解決。導音（シ）は主音（ド）へ。**次のステップの頭と同じ音は、つないで、シンコペーションにしてもよい**（両方の和音のコードの音か 9th のときだけ） | 声部の動き（ボイスリーディング）の考え方 |
| **まねる** | 2小節目・3小節目で、前と同じリズムの型のところは、前の動き方（音の間隔）をまねる | モチーフのくり返し |
| **音域** | G4〜F6（中心は F♯5） | 歌いやすい高さ・和音（C3〜）とぶつからない高さ |
| **終わり** | 最後は、コードの音で、長く。トニックの和音なら、ルート（ド）か 3度（ミ）を、さらに好む | 終止感 |
| **休み** | 和音のないステップには、音を置かない | — |
| **音の呼び名** | 和音の書き方にそろえる（Ⅰ7 の 7th は「シ♭」・Ⅲ7 の 3度は「ソ♯」・Ⅱ♭7 のルートは「レ♭」） | 説明の文に出る名前が、和音の名前と合うように |

### 5-2. できばえの点（360 通りから選ぶ基準）

和音との相性（`core/melody.js` の採点）× 60 / 順次進行の割合 / 跳躍の使いすぎ・大きな跳躍の減点 / 同じ音の連続の減点 / 9th が 1〜3つ（加点）・多すぎる（減点）/ 使った音の種類（6〜7種類まで加点）/ 音域（8〜15半音が良い）/ 1ステップあたりの音の数（2.1〜3.6が良い）/ **リズムの型の種類（3種類以上が良い）**・短い音の数 / 山（いちばん高い音）が後ろのフレーズ（5〜7番）にあるか / 1小節目と3小節目の動きの向きの似かた / 終わりの音の長さ / 最後の音から最初の音への、つなぎ目の近さ（ループするため）。

### 5-3. 作風

| 作風 | 特徴 | 平均の音数 |
|---|---|---|
| なめらか（標準） | ゆったり。長めの音が多い | 約 15 |
| リズミカル | 8分音符とシンコペーションが多い。同じ音の連打も出る | 約 16 |
| やさしい | 4分音符が中心。音が少なめ | 約 14 |

## 6. プリセット（コードとメロディ）

- **保存**: 「☆ プリセット」で範囲（1〜8番のうち、つながった部分）を選ぶと、メロディがその範囲にあるとき「**メロディもいっしょに保存する**」のチェックが出る（初期は ON）。または「♪ メロディ」の画面の「コードとメロディをプリセットに保存」（盤の、最初の駒〜最後の駒の範囲）。
- **形**: `{ id, name, chords: ['ⅣM7', 'Ⅴ7', ...], melody: [[開始のマス, 長さ, 高さ], ...], at }`。メロディの開始は、**範囲の左端（最初のコード）からのマス**。範囲の外にはみ出す音は切る。前後の空きを切り落とすと、メロディの位置も合わせて直る。
- **呼び出し**: 駒が置かれて（「置く場所」の番号に合わせて）、**その範囲のメロディが、プリセットのメロディに置きかわる**。範囲の外のメロディは、そのまま（範囲をまたぐ音は、範囲の中だけ消える）。**メロディのないプリセットは、メロディをさわらない**。実機の盤のときは、駒は「案内」（画面では置けない）。メロディは、すぐ入る。
- **同じコードでも、メロディがちがえば、別のプリセット**として保存できる（同じコード・同じメロディは「保存ずみ」）。
- 30個まで・名前は 20文字まで・ブラウザに保存（「進み具合をリセット」でも消えない）。

## 7. 保存先

- つくったメロディ: ブラウザの localStorage（`chordlines.v1` の `userMelody`）。ページを読み込み直しても残る。「進み具合をリセット」でも消えない（プリセットと同じ）。
- 「メロディの音 ON/OFF」: `userMelodyOn`。

## 8. 私の解釈（違っていたら教えてください）

1. **「テンションは 9th まで」= 強い拍・長い音には、コードの音と 9th だけ。** 11th・13th・♭9・♯9 は使わない。短い経過音でも、それらに聞こえる音は使わない。**9th を使ってよいのは、調の音階の中にあるとき（と、ドミナント7th のとき）だけ**にした（Ⅲm7 の ファ♯ のような音階の外の 9th は、音がぶつかりやすいので外した）。「9th の ♭9・♯9 も 9th のうち」と読むなら、ドミナント7th にだけ足せる。
2. **「センスのある」= ルールと、360通りから選ぶ点で作った。** 耳で確かめていない（下の 9章）。気に入らなければ「別の案にする」と、編集で直せる。
3. **メロディは単旋律**（1度に1つの音）で作る。編集の画面では、重ねて和音のように書くこともできる。
4. **メロディの高さは、C メジャーの主音 = C で固定**（ゲームの盤は、いつも C を主音として鳴らすため）。
5. **フリープレイの得点には、メロディを入れていない**（「合わせる」のステージだけ、メロディの点が入る）。「♪ メロディ」の画面で、和音との相性（%）と、音ごとの説明が出る。得点に入れたいなら、変えられる。
6. **音の長さの単位 = 16分・8分・4分・2分**（付点は、ドラッグで 3マス・6マスにすれば作れる）。

## 9. 確かめたこと・確かめていないこと

**確かめたこと（パソコン上の自動テスト）**
- 自動メロディ: ステージのお手本・タイトルの進行・でたらめな盤を含む **834 通り**（盤 139 × 作風 3 × 9th あり/なし 2）で、**失敗 0・決まりの違反 0**・和音との相性は平均 **98%**・最低でも 85% 以上。1回の計算は 平均 約 6.6 ms（最大 約 21 ms）。
- 決まり（`checkRules`）: 強い拍・長い音がコードの音か 9th / 9th を使わない設定で 9th が 0 / 経過音が 11th・13th・7th に聞こえない / 和音のないステップに音がない / 音が重ならない / 跳躍が大きすぎない / 音域の中。
- 同じ種 → 同じメロディ。種がちがえば、ちがうメロディ（12 通りのうち 10 通り以上が別）。
- 編集の道具（`usermelody.js`）: 追加・動かす・長さ・消す・重なりの整理・元に戻す/やり直す（ドラッグは1回にまとめる）・壊れた保存の検査。
- 画面（本物の Chrome で、マウス・キーボードの操作どおり）: クリックで置く・ドラッグでのばす・動かす・右はしで長さ・Delete・矢印キー・右クリック・元に戻す/やり直す・自動・作風・9th OFF・保存（読み込み直しても残る）・プリセット（保存・位置のずれ・範囲だけ置きかわり・メロディのないプリセットは触らない・実機の盤のとき）。再生位置の線・メロディのエンジンへの反映・「メロディの音 OFF」も、音あり（AudioContext）で確認。
- 画面の見た目: 1280×720・1920×1080・1024×640 で、崩れないことを確認（写真は `docs/screens/` の 31〜34 = メロディの画面・音を選んだところ・プリセットのメロディ欄・チャレンジ終了後のバー）。

**確かめていないこと**
- **自動でつけたメロディが、音楽として「センスがある」か（耳）。** ルール・点は、私が理論から決めた。メロディの音色（笛のような合成音）の大きさも、耳では確認していない。
- 実機の盤（本物の駒）を動かしながら、画面を開いたときの手応え。
- Chrome 以外のブラウザ。
