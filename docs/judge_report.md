## 1. 先に結論

- 名前のついた技（20個＋借用和音2個 = 23個）にならない並びにも、**ルール**で採点します。この採点役を、ゲームの中では **「ジャッジ」** と呼びます（右の「技」の一覧に、緑／赤／灰色の行で出ます）。
- 「AI」といっても、**学習したモデルではありません**。決まりごとを書いた**ルールの審判**です。理由は3つ。①なぜその点なのか、画面の文章で説明できる（学習したモデルは、理由を言えない）②同じ盤なら、いつも同じ点になる（ゼミで再現できる）③ルールごとに、自動テストで確かめられる。
- 裁量は、全部で **加点6種・減点2種・指摘1種**、そして **借用和音の技2種**（サブドミナントマイナーと、その代理）。ヒントも、同じ考え方で広げました（9章）。
- 点数は**仮**です（ゲーム全体の点数と同じ）。耳で聴いて「この進行にこの点は、おかしい」と思ったら、数字を変えるだけで直せます（10章）。**あなたの耳での確認は、まだです。**

## 3. 点数のしくみ（総得点の式）

```
総得点 = 技の点 × 種類の倍率 + コードの難しさの加点 + ジャッジの加点 − ジャッジの減点 − 「？」の減点
         （0 点より下にはならない）
```

- 技の点: 技ごとの点 × 繰り返しの倍率（同じ技の2回目は ×0.6…）× コンボ（つながった技の数 ×1.5・×2…）。
- **ジャッジの点は、コンボ・種類の倍率には入れません**（足し算だけ）。ジャッジで技の数・図鑑は増えません。
- **二重に数えない**: 名前のついた技が取ったつながりは、ジャッジは加点しません。階段・声の動き・進行感なしは、並びの中に「技に取られていないつながり」が1本でもあれば数えます。機能のながれ（3和音）は、2本とも技に取られたときだけ数えません。
- 次のときは、ジャッジは**働きません**: 最初のチュートリアル（「はじめに」。置いて聴くだけ）／ タイトルのデモ。チュートリアルのクリア条件にも使いません（技だけで決まります）。
- 「休み」（空き駒）をはさむと、並びは切れます。「→」と、小節の頭の Ⅴ（？）は、並びに入れません。

## 4. 前提: 「つながり」の性質（`edgeInfo`）

隣り合う2つの和音を、ルートの動き（半音数・上向き）と、共通音の数で分類します。ジャッジのほとんどが、これを使います。

| ルートの動き | 自然さ | 理由の文章 |
|---|---|---|
| 4度上（5半音）・5度上（7半音） | 2（強い理由あり） | 強進行・弱進行 |
| 半音・全音の上下（1・2・10・11半音） | 1 | 階段のようになめらか |
| 同じルート（0半音） | 1 | 同じルートの、響きの変化 |
| 短3度・長3度の上下（3・4・8・9半音） | 共通音2つ以上、または、同じ働き（トニックどうし・サブドミナントどうし）なら 1。そうでなければ **0** | |
| 増4度（6半音） | ドミナント7th どうしなら 2（裏コード）。そうでなければ **0** | |

**自然さ 0 = 「つながる理由が見つからない」**（減点の材料）。

和音の働き（見た目用の仮の分け方）: トニック系 T = Ⅰ・ⅠM7・Ⅲm・Ⅲm7・Ⅵm・Ⅵm7 ／ サブドミナント系 SD = Ⅱm・Ⅱm7・Ⅳ・ⅣM7・Ⅳm7・Ⅳm6 ／ ドミナント系 D = Ⅴ・Ⅴ7・Ⅴsus4・Ⅶm7♭5・各ドミナント7th（Ⅰ7・Ⅱ7・Ⅲ7・Ⅵ7・Ⅱ♭7）・Ⅶ♭7 ／ それ以外 X（借用・経過。機能のながれには使わない）。

## 5. 加点の裁量（6種）

### G1. ベースラインの階段（+60 / +90 / +120）
- 条件: 休みで切れない並びの中で、**ルートが半音か全音ずつ、同じ向きに**動き続ける和音が **3つ以上**。
- 点: 3つ +60、4つ +90、5つ以上 +120。
- 例: `Ⅰ → Ⅱm → Ⅲm → Ⅳ`（のぼる、+90）／ `Ⅳ → Ⅲm → Ⅱm → Ⅰ`（おりる、+90。ほかに「半音下への進行」の技も別に入る）。
- ねらい: ベースが階段のように動くと、技の名前はなくても、「進んでいく感じ」が出る。
- 理由の文章: 「Ⅰ → Ⅱm → Ⅲm → Ⅳ。ルートが、半音・全音ずつ、上へ動き続けます。ベースの音が階段のように並ぶので、進んでいく感じ（進行感）が生まれます。」
- 注意: 階段が伸びるたびに、通知の点を更新します（+60 → +90）。

### G2. 機能のながれ（+50 / +30）
- 条件: 続く3つの和音の「働き」が、
  - **SD → D → T**（広がる → 緊張 → 安定）: **+50**「おしまいへ向かう」。例: `Ⅳ → Ⅴ7 → Ⅰ`（Ⅴ-Ⅰ終止の技とは別に数える）
  - **T → SD → D**（安定 → 広がる → 緊張）: **+30**「盛り上がる」。例: `Ⅰ → Ⅱm → Ⅴ`
- 除外: 「→」・「？」を含むとき／ 2本のつながりが両方とも、技に取られているとき（例: `Ⅰ → Ⅳ → Ⅴ` は、強進行とドミナント終止の技が2本とも取るので、加点なし）。
- ねらい: コード進行のいちばん基本の流れ（トニック・サブドミナント・ドミナント）を、技にならなくても、評価する。

### G3. 導音の解決（+40）
- 条件: **Ⅶ（Ⅶm7♭5）の次が、Ⅰ か ⅠM7**（Ⅰ7 は含めない）。そのつながりが、技に取られていない。
- 例: `Ⅶm7♭5 → Ⅰ`。
- ねらい: Ⅶ（シ）が、半音上の Ⅰ（ド）へ進みたがる引力（導音）どおりに、解決している。

### G4. なめらかな声の動き（+40）
- 条件: **和音3つ以上**で、となりどうしが、**どれも共通音2つ以上**（技に取られていないつながりが1本以上）。
- 例: `Ⅰ → Ⅵm → Ⅳ`（Ⅰ と Ⅵm は ド・ミ、Ⅵm と Ⅳ は ラ・ド を共有）。
- ねらい: 音の動きが小さく、なめらかにつながる並びは、耳に馴染みやすい。

### G5. サス（sus4）の解決（+40）— 2026-11-17 に追加
- 条件: **sus4 の和音（いまの駒では Ⅴsus47）の次が、同じルートの長三和音か、ドミナント7th**（Ⅴsus47 → Ⅴ・Ⅴ7）。そのつながりが、技に取られていない。小節の頭（1番・5番）の Ⅴsus47 は「？」なので、数えません。
- 点: +40（導音の解決と同じ。1つの盤で、何か所でも。ただし、加点の合計上限 +240 の中）。
- 例: `Ⅰ → Ⅴsus47 → Ⅴ7 → Ⅰ`（弱進行 60 + Ⅴ-Ⅰ終止 200 に、サスの解決 +40 と、なめらかな声 +40 が加わる）。`Ⅴsus47 → Ⅰ`（ルートが変わる）や、`Ⅴ7 → Ⅴsus47`（逆向き）は、サスの解決ではありません。
- ねらい: sus4 の「4度の音」（Ⅴsus47 なら ド）が、半音さがって「3度の音」（シ）へ動くときの、内側の声（内声）だけが動く、ほどけるような解決を評価する。ルートと5度の音は動かず、Ⅴsus47 → Ⅴ7 では、ソ・レ・ファ の3つが、そのまま残る。
- 理由の文章: 「Ⅴsus47 → Ⅴ7。sus4 の『4度の音』が、半音さがって、『3度の音』へ。ルートと5度の音は動かず、内側の声（内声）だけが、すっと動いて、ほどけるように解決します。」
- ヒントにも出ます: Ⅴsus47 の次の候補に、Ⅴ（Ⅴ7）が「サス（4度の音）が、半音さがって、3度の音へ。内声が、すっと解決する」の理由つきで、おすすめ（重み 6）として出ます。
- 補足: 2026-11-18 に、Ⅵsus4（3和音のサス。ID 31）を駒に足しました（Ⅵsus4 → Ⅵ で、同じ規則が効きます。ただし、Ⅵ への着地は、ピカルディ終止の技が取るので、ふつうは重ねて数えません）。`isSus` は `sus47`・`sus4` の両方を見ます。

### G6. 解決（+60）— 2026-11-18 に追加（ご指摘「Ⅰ や Ⅵ で終わったら、解決として加点して」）
- 条件: **フレーズの終わり**の和音が、**安定したトニック** — **Ⅰ・ⅠM7（Ⅰ系）、Ⅵm・Ⅵm7（Ⅵm系）**。
  - フレーズの終わり = **4番・8番に着く駒**、または**その後に続く駒がない駒**（休み・盤の終わり）。終止の技と同じ決まり。
  - Ⅰ7・Ⅵ7（次のコードを引っぱる、セカンダリードミナント）と、Ⅵ（長三和音。ピカルディ終止の着地点）は、**含めない**。
  - 直前の和音とルートが違うこと（Ⅵm → Ⅵm7 のような、同じルートの響きの変化は、解決ではない）。2つ以上の和音がつながっていること（1つだけの駒には付かない）。
- 点: +60。1つの盤で、**最大2回**（加点の合計上限 +240 の中）。
- **二重に数えない**: その駒へのつながりを、**名前のついた技**（終止・固有進行・借用和音の技）が取っているときは、付けません（Ⅴ-Ⅰ終止・偽終止・王道進行など。その技の点が、着地を評価しているため）。**ふつうの強進行・弱進行・半音下**が取っているだけなら、付けます。
  - その結果、Ⅵm で終える形は、ほとんどが偽終止（200）になるので、解決の +60 は、**実質、Ⅰ系で終える形**に付きます。
- 例: `Ⅱm7 → ⅠM7`（+60。技にはならない）／ `Ⅳ → Ⅰ`（弱進行 60 + 解決 60。変格終止の形）／ `Ⅲm7 → Ⅰ`・`Ⅶm7♭5 → ⅠM7`。`Ⅴ7 → Ⅰ` は、Ⅴ-Ⅰ終止（200）が評価するので、付かない。
- ねらい: 緊張や広がりから、安定した和音へ着地して、フレーズが「ひと区切りついた」感じを、技の名前がなくても評価する。
- 理由の文章: 「Ⅱm7 → ⅠM7。フレーズの終わりを Ⅰ（トニック）で終えました。広がりや緊張から安定した和音へ着地して、ひと区切りついた感じ（解決）があります。」
- ヒントにも出ます: 4番・8番に置く候補として、Ⅰ系・Ⅵm系が「フレーズの終わりを Ⅰ で終えると安定した和音へ着地して『解決』の加点」の理由つきで、発展に出ます（すでに名前のついた技が決まる駒は、その理由を出します）。

## 6. 減点・指摘の裁量

### B1. 進行感がない（−40）
- 条件: **和音3つ以上**が続いて、**どのつながりも「自然さ 0」**（4章の表）で、技に取られていない。
- 点: 連なり1つにつき −40（1つの盤で、3か所まで）。
- 例: `Ⅰ → Ⅲ7 → Ⅵ♭M7`（Ⅰ→Ⅲ7 は長3度で共通音1つ、Ⅲ7→Ⅵ♭M7 も共通音1つ。どちらにも、つながる理由がない）。
- 理由の文章: 「どのつながりも、共通音が少なく、ルートの動きにも『つながる理由』（4度・5度・階段・入れ替え）が見つかりません。進んでいく感じ（進行感）がなく、唐突に聞こえます。間に、つなぎ役の和音を入れてみよう。」（**ただ減点するのではなく、直し方を一言そえる**）
- 1つでも「理由のあるつながり」が混じっていれば、減点しません（厳しすぎないように、3つ続いたときだけ）。

### B2. 唐突な借用和音（−30）
- 条件: **借用和音**（Ⅳm7・Ⅳm6・Ⅱ♭M7・Ⅵ♭M7・Ⅶ♭7・Ⅲ♭M7・Ⅲ♭m6）が、前後に和音がある位置にあって、
  ① 前の和音から、つながる理由がない（自然さ 0。ただし Ⅳ → Ⅳm は理由あり）、かつ
  ② 次の和音が、7章の「自然な着地」の表にない。
- 点: −30（1つの盤で、3か所まで）。技（サブドミナントマイナー・代理）にはならない。
- 例: `Ⅲ7 → Ⅵ♭M7 → Ⅱ♭7`（Ⅲ7→Ⅵ♭M7 は共通音1つ。Ⅵ♭M7 の次に Ⅱ♭7 は着地表にない）。
- 片方でもつながっていれば、減点しません（例: `Ⅰ → Ⅵ♭M7 → Ⅲ7` は、Ⅰ と Ⅵ♭M7 が共通音2つなので、技にも減点にもならない）。

### 指摘（0点）: 同じ和音が続いています
- 条件: 同じ駒が、となりに並んでいる。
- 内容: 点は変わりません。「同じ響きをのばしたいときは、『→』の駒を使うと、1つぶん、のばせます」と、案内するだけ。

## 7. 借用和音（サブドミナントマイナー系）の技

「Ⅳ の ラ を ラ♭ に変えた、短調から借りてきた和音」と、同じ短調の色をもつ和音を、**不自然でなく着地できたとき**だけ、技にします（着地できない借用は、B2 で減点）。技の一覧では「借用和音」の仲間（番号 22・23）。

### 7-1. 技「サブドミナントマイナー」（番号22）

| パターン | 条件 | 点 | 優先度 |
|---|---|---|---|
| Ⅳ → Ⅳm → Ⅰ（Ⅴ） | Ⅳ（Ⅳ・ⅣM7）→ Ⅳm（Ⅳm7・Ⅳm6）→ Ⅰ系（Ⅰ・ⅠM7・Ⅰ7）または Ⅴ系（Ⅴ・Ⅴ7・Ⅴsus4） | **300** | 82（終止より先に取る） |
| Ⅳm系 → 自然な着地 | Ⅳm7・Ⅳm6 の次が、下の「自然な着地」の和音 | 120 | 75 |

- `Ⅰ → Ⅳm7 → Ⅰ` は、直前が Ⅳ・ⅣM7 ではないので、上の300点の形にはならず、**「Ⅳm系 → 自然な着地」の技（120）**になります（**ピカルディ終止ではありません**。2026-11-18 の訂正。ピカルディ終止は、Ⅵm で終わるところを Ⅵ（長三和音）で終える技で、`theory_audit.md` の5章）。

### 7-2. 技「サブドミナントマイナーの代理」（番号23）

| パターン | 条件 | 点 |
|---|---|---|
| ネアポリタン進行 | Ⅱ♭M7 → Ⅴ系 → Ⅰ系（Ⅴ → Ⅰ が、終止に取られない位置のとき） | 240 |
| 代理の和音 → 自然な着地 | Ⅱ♭M7・Ⅵ♭M7・Ⅶ♭7・Ⅲ♭M7・Ⅲ♭m6 の次が、自然な着地の和音 | 100 |

- 呼び名（変種）: ネアポリタン（Ⅱ♭M7）／ ♭Ⅵ ／ ♭Ⅶ ／ ♭Ⅲ ／ ♭Ⅲm6。
- `Ⅱ♭M7 → Ⅴ → Ⅰ` は、Ⅰ が**フレーズの終わり（4番・8番）か、並びの最後**にあるときは、「ネアポリタン（100）＋ Ⅴ-Ⅰ終止（200）」の**2つの技がつながり（コンボ ×1.5 で 150 + 300）**ます。Ⅰ のあとに駒が続いて、終止にならないときは、「ネアポリタン進行」（240）の1つの技になります（例: `Ⅱ♭M7 Ⅴ Ⅰ Ⅳ` → 240 × 1.5 = 360 ＋ 強進行 150）。
- Ⅱ♭7（裏コード）は、別の技（半音下への進行・裏コード）なので、ここには入れていません。

### 7-3. 「自然な着地」の表（`naturalAfterBorrowed`）

借りた和音の**次**に、この和音が来たら「自然」。

## 9. ヒントの幅（今回の追加）

ヒントは、判定の定義から**計算**します（手で書いた表ではありません）。今回、候補の種類と数を広げました。数は、おすすめ 3 → **4**、発展 3 → **5**。

| 種類 | 条件 | 出る場所 | 例 |
|---|---|---|---|
| 技が決まる駒 | 置くと、名前のついた技が決まる | おすすめ | 3番 Ⅴ7 のあと、4番 Ⅰ → Ⅴ-Ⅰ終止 |
| 進行の途中 | 名前のついた進行の、次の1つ（1番・5番から） | おすすめ（借用和音は発展） | Ⅵm → Ⅳ のあと Ⅴ → 小室進行 |
| **流れのヒント（新）** | 左の駒から、自然に続く駒。つながりの重みが大きい5以上は「おすすめ」、それ以外は「発展」 | 両方 | 下の表 |
| **フレーズの終わりへ（新）** | 3番・7番で、Ⅴ系を置くと、次を Ⅰ にして終止にできる | 発展（ドミナント終止などの技が、そのとき決まるなら、おすすめ） | 3番に Ⅴ → 4番を Ⅰ に |
| **ループのつなぎ目（新）** | 8番を置くとき、1番の駒へ自然につながる駒 | 発展（その駒で技が決まるなら、おすすめ） | 8番に Ⅴ（→ 1番の Ⅰ） |
| 先読み | 色の濃い駒で、次の1つを置くと技になるもの | 発展 | ⅣM7 のあと Ⅳm7（次に Ⅰ でサブドミナントマイナー） |

**流れのヒントの重み**（`flowReason`）: **サスの解決 Ⅴsus47 → Ⅴ（Ⅴ7）（6。2026-11-17 に追加）**／ Ⅴ → Ⅰ（6）／ Ⅱm → Ⅴ（ツーファイブ、6）／ Ⅴ → Ⅵm（偽終止、5）／ **Ⅵm → Ⅱm（循環コード、5）** ／ 導音 → Ⅰ（5）／ Ⅳ → Ⅳm（4）／ 借用和音 → 自然な着地（4）／ 階段の続き（4）／ 強進行（4）／ 弱進行（3）／ Ⅰ ⇄ Ⅵm（3）／ 共通音3つ以上（2）。

- あなたの例: **4番が Ⅵm 系のとき、5番（小節の頭）のおすすめに Ⅱm7**（循環コードの流れ。Ⅰ → Ⅵm → Ⅱm → Ⅴ）。実際に、`Ⅰ Ⅳ Ⅴ Ⅵm7` のとき、5番のいちばんのおすすめは Ⅱm7 になります（自動テスト済み）。
- 小節の頭（1番・5番）では、「進行の最初の駒」より、**前の駒からの流れ**を先に出します。小節の頭の Ⅴ（？）は、いつものとおり、出しません。
- 物理的な盤を使っていないとき、**ヒントの札を、クリックすると、その駒が置かれます**。

### 限界（ルールの審判だから、起きること）
1. **キーは C 固定の度数で見る**ので、転調は扱えません。
2. 見るのは、**ルート・構成音・働き**だけです。リズム・実際の声部の高さ・メロディは見ません。
3. 映画音楽にあるような、**長3度・短3度の飛び**（クロマティック・メディアント）は、共通音が少ないと「理由なし」と見られます。ただし、減点されるのは、3つ続いたときだけで、−40 までです。
4. 「耳に馴染む」の基準は、**わたし（Claude）が音楽理論から決めた仮の基準**です。あなたの耳・ゼミの先生の基準とは、ずれる可能性があります。

### 確かめたこと / まだ確かめていないこと
- **確かめた（自動テスト・パソコン上）**: 上の例の判定結果と点数／ 上限／ 同じ盤は同じ結果／ 技が取ったつながりを、二重に数えない／ ステージ0 では働かない／ 画面の表示（行・チップ・通知・「理由」の欄）／ ヒントの数と、あなたの例（Ⅵm7 のあと Ⅱm7）。
- **まだ確かめていない**: ①**耳で聴いて、点が納得できるか**（あなたにしか分かりません）②点数のバランス（遊んだときの手応え）③実機の盤での遊び心地。ゼミで、先生に聞いてみたいことは、「進行感のない進行は、減点してよいか」「借用和音は、どこまで評価するか」です。
