## 5. ピカルディ終止の新しい定義

- **着地点**: Ⅵ（長三和音。Key=C なら A）。**フレーズの終わり**（4番・8番、または、その後に駒がない）で決まります。
- **直前の和音**（イ短調 = Ⅵm を主和音と見たときの、終止に向かう和音）:

| 直前 | イ短調で見ると | 例（Key=C）|
|---|---|---|
| Ⅲ7 | Ⅴ7（属七） | E7 → A |
| Ⅴ・Ⅴ7・Ⅴsus47 | ♭Ⅶ（アンダルシア・ロックの終わり方）| G7 → A |
| Ⅱm・Ⅱm7 | Ⅳm（アーメン終止の形。Wikipedia の「よくある形」）| Dm7 → A |
| Ⅵm・Ⅵm7 | 主和音そのもの（短三和音 → 長三和音）| Am7 → A |
| Ⅵsus4 | 主和音のサス | Asus4 → A |

- **点**: 250。直前が Ⅵsus4 のときは **「サスつき」+50 = 300**（サスの解決。G5 の +40 とは重ねない）。
- **ヒント**: 「おすすめ」ではなく**「発展」**に出る。Ⅲ7・Ⅵm 系・Ⅵsus4 からの形は、どこでも出る。Ⅴ・Ⅱm からの形は、フレーズの終わり（4番・8番）でだけ出る（毎回 Ⅵ が出ないように）。
- **ご指摘の例**: ⅣM7 → Ⅴ7 → Ⅵsus4 → Ⅵ（イ短調で見ると ♭ⅥM7 → ♭Ⅶ7 → Ⅰsus4 → Ⅰ）。終止の囲みは、後ろの2つ（Ⅵsus4 → Ⅵ）。

## 10. 第10弾（2026-11-24 夜）: ヒントの自然さ・スムーズボイスリーディング・低すぎる進行

### 10-1. ご指摘（ヒント）

- 画像: ⅠM7 → Ⅶm7♭5｜Ⅲ7（分割したマス）の次の**3番**で、第一候補が **Ⅵ（長三和音）だけ**。「ピカルディ終止ならまだしも、3個目のマスですし」「Ⅵm7 が候補に上がっていないのもおかしい」「トライアドなので、セカンダリードミナントというわけでも無さそう」「ほかのダイアトニックコードを差しおいて、それが候補にひとつだけ上がる」「画像のほかの候補も、中々不自然」。
- 「ヒントは、不可解な候補を挙げることがかなり多い。**すべての進行の続きのヒントを、自然に。ただし、新しい発見はつぶさないように、丁寧に**」。

### 10-2. 原因（調べて分かったこと）

1. **同じルートの和音を、点数の高い1つにまとめていた**（ルートごとに1つ）。Ⅲ7 のあとの Ⅵ・Ⅵm・Ⅵm7 は、ガイドトーンの半音進行（D → C♯）の加点がつく **Ⅵ（長三和音）が、いちばん高く**、Ⅵm7・Ⅵm は消えていた。Ⅲm7 のあとの Ⅵ7（セカンダリードミナントの +50）が Ⅵm7 に勝つ・Ⅵm7 のあとの Ⅱ7 が Ⅱm7 に勝つ、も同じ原因。
2. **先読みの候補が、前の駒とのつながりを見ていなかった**。「次に何かを置くと、技になる」駒を出すとき、いまの駒（前の駒の次）が自然かを調べていなかった。そのため、Ⅲ♭m6・Ⅴ#dim7・Ⅱ♭7 などが、どこでも出た。
3. **強進行・弱進行・半音下は、ルートの動きだけで当たる**。Ⅲ7 → Ⅲ♭m6（半音下）・Ⅴ7 → Ⅳ#m7♭5（半音下）・Ⅲ7 → Ⅶm7♭5（5度上）などが、「技が決まる」として出た。
4. **ピカルディ終止を、3番でも勧めていた**（第4弾の決め。Ⅲ7 → Ⅵ は、いつでも）。

### 10-3. 「自然さ」のものさし（`core/continuation.js`）

**level 3 = いつもの流れ / 2 = よくある流れ / 1 = ときどきある流れ / 0 = 不自然**（ヒントには出さない。名前のついた技・進行の途中は、技の定義が、そう決めているので、別に扱う）。技の判定・点数には、使わない（ヒントの順位と足切りだけ）。

**（1）その調の音だけでできた和音どうし = Piston の「ふつうの根音進行の表」**（Walter Piston『Harmony』の "Table of Usual Root Progressions"）:

| いまの和音 | ふつうは（3） | ときに（2） | まれに（1） |
|---|---|---|---|
| Ⅰ | Ⅳ・Ⅴ | Ⅵ | Ⅱ・Ⅲ |
| Ⅱ | Ⅴ | Ⅳ・Ⅵ | Ⅰ・Ⅲ |
| Ⅲ | Ⅵ | Ⅳ | Ⅱ・Ⅴ |
| Ⅳ | Ⅴ | Ⅰ・Ⅱ | Ⅲ・Ⅵ |
| Ⅴ | Ⅰ | Ⅳ・Ⅵ | Ⅱ・Ⅲ |
| Ⅵ | Ⅱ・Ⅴ | Ⅲ・Ⅳ | Ⅰ |
| Ⅶ | Ⅲ | Ⅰ | — |

- **確かめたのは、Ⅰ と Ⅱ の行だけ**: ウェブ上の紹介記事（Dale McGowan "The Secret Hidden Grammar of Music"。Soundfly / [Hypebot](https://www.hypebot.com/the-secret-hidden-grammar-of-music/)、2021）が、表を**ハ長調に書き直した文**を載せていた。「C は F か G へ。ときに Am。まれに Dm か Em」（= Ⅰ の行）・「Dm は G へ。ときに F か Am。まれに C か Em」（= Ⅱ の行）。記事には、教科書の表の画像もあるが、文字では取れなかった。
