## 5. ピカルディ終止の新しい定義

- **着地点**: Ⅵ（長三和音。Key=C なら A）。**フレーズの終わり**（4番・8番、または、その後に駒がない）で決まります。
- **直前の和音**（イ短調 = Ⅵm を主和音と見たときの、終止に向かう和音）:

| 直前 | イ短調で見ると | 例（Key=C）|
|---|---|---|
| Ⅲ7 | Ⅴ7（属七） | E7 → A |
| Ⅴ・Ⅴ7・Ⅴsus47 | ♭Ⅶ（アンダルシア・ロックの終わり方）| G7 → A |
| Ⅱm・Ⅱm7 | Ⅳm（アーメン終止の形。Wikipedia の「よくある形」）| Dm7 → A |
| Ⅵm・Ⅵm7 | 主和音そのもの（短三和音 → 長三和音）| Am7 → A |
| Ⅵsus4 | 主和音のサス | Asus4 → A |

- **点**: 250。直前が Ⅵsus4 のときは **「サスつき」+50 = 300**（サスの解決。G5 の +40 とは重ねない）。
- **ヒント**: 「おすすめ」ではなく**「発展」**に出る。Ⅲ7・Ⅵm 系・Ⅵsus4 からの形は、どこでも出る。Ⅴ・Ⅱm からの形は、フレーズの終わり（4番・8番）でだけ出る（毎回 Ⅵ が出ないように）。
- **ご指摘の例**: ⅣM7 → Ⅴ7 → Ⅵsus4 → Ⅵ（イ短調で見ると ♭ⅥM7 → ♭Ⅶ7 → Ⅰsus4 → Ⅰ）。終止の囲みは、後ろの2つ（Ⅵsus4 → Ⅵ）。

## 8. ドライブシンセ（音と立ち上がりの遅れ）

- **原因**: 以前の「サイドチェイン」は、拍の頭から半拍近く引っ込んだままで、裏拍から**ゆっくり**立ち上がり、いちばん大きくなるのは**次の拍の頭の直前**でした。数値にすると、**BPM120 で、拍の頭から半分の大きさに戻るまで 約 0.42 秒**（拍の約8割）。和音の入りも、拍よりずっとあとに聞こえます。
- **直し方**（`instruments.js` の `PUMP`）: キックに押さえられるのは**ほんの一瞬**（拍の頭の 2%）。すぐ戻りはじめて、はじめは速く、終わりはゆるやかに戻る（イーズアウト）。音の明るさ（フィルター）は**拍の頭でいちばん明るく**（「ツン」とした立ち上がり）、そのあとまるくなる。
- **測った結果**（BPM120、和音 C3・G3・C4、拍の頭から。マスターのコンプレッサーの遅れ 6ms を見込む）: 引っ込みは元の **11%**（約 0.03 秒）／**25% まで 約 0.025 秒・50% まで 約 0.06 秒・75% まで 約 0.12 秒**。BPM90 では 50% まで 約 0.1 秒（拍の 0.15）・BPM150 では 約 0.04 秒（拍の 0.1）。以前は、50% まで 約 0.42 秒（以前の曲線からの計算）。
- **音量**: 鳴っている時間が長くなって、ふだんの大きさが約 2.5 倍になった（ピアノとの音量比 0.76 → 1.93）ので、ゲインを 0.3 → 0.15 に下げた（音量比 約 1.3。メロディの笛と同じくらい）。
- **サカナクションの参考**: 資料（2章）の言葉から、「ツンとしたアタック = フィルターのエンベロープ」と「テンポに合った動き」を取り入れた。**サイドチェインの設定値・波形の資料は見つからなかった**ので、あの音そのものではありません。**耳での確認は、まだです。**
