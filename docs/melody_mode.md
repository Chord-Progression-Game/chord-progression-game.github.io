# 「メロディにコードをつける」ステージ（メロディとの相性の採点）

- 作成: 2026-11-17 ／ 対象: `game/`（ゲーム本体）／ 読む人: あなた（ゼミ・学内発表の資料にも使えます）
- 依頼: 「流れているメロディに対してコード進行を作り、通常と同様にコード進行としての採点をしつつ、メロディとの相性（コードトーンや、9thなどの適切なテンションがメロディとなっているか、コードトーンがメロディに対するアヴォイドノートになっていないか、等々）も加えて採点するものを追加してほしい」

## 1. 先に結論

- タイトルの **「合わせる」**（メロディにコードをつける）から入る、新しい遊び方を追加しました。メロディは **5つ**（どれも、このゲームのために書いた、オリジナル。C メジャー）。
- 流れるメロディに合うと思う和音を、盤の1〜8番に置きます。画面の上の **「メロディの帯」** に、メロディの1つ1つの音が、**いま鳴っている和音に対して、どう聞こえるか**が、色で出ます。置き終わったら「できた！ 採点する」。
- **得点 = コード進行の点（技・ジャッジ。ふだんと同じ）+ メロディとの相性の点**。メロディとの相性は、満点 **1,200 点**（+ テンションのボーナス 最大 120 点）です。
- 相性は、**ルールで決めています**（学習したモデルではありません）。なぜその点なのかは、帯の音や、列をクリックしたときの「理由」の欄に、文章で出ます。
- 点数・判定の決まりは**仮**です。**耳での確認は、まだです**（11章）。

## 2. 遊び方の流れ

1. タイトル →「合わせる」→ メロディを選ぶ（5つ）。ステージ選択（「選ぶ」）の中の「メロディにコードをつける」からも入れます。
2. メロディが流れます（和音・ドラムと同じテンポで、1周 = 8ステップ = 4小節。1ステップ = 盤の1つの場所 = 2拍）。メロディの音は、やわらかい笛のようなシンセです。
3. 駒を置くたびに、帯の音の色・各ステップの点・相性（%）が変わります。右の「技」の一覧には、コード進行の技・ジャッジに加えて、ぶつかっているステップの知らせが出ます。
4. 「できた！ 採点する」→ 結果の画面（得点・星・ステップごとの表・星の条件・お手本の一例）。「盤面にもどる」で、盤をそのまま直せます。
5. ヒントを ON にすると、次に置く場所のメロディに合う和音の候補が出ます（8章）。

## 3. 点数のしくみ

```
総得点 = コード進行の点（技・ジャッジ・難しさの加点 − 「？」の減点）+ メロディとの相性の点
         （0 点より下にはならない）
```

- コード進行の点は、ふだんと同じ（`docs/judge_report.md` と `docs/tricks_spec.md`）。サスの解決（Ⅴsus47 → Ⅴ7）の加点も、ここに入ります。
- メロディとの相性の点 = 各ステップの点の合計 + テンションのボーナス。

## 4. メロディの音を、4つに分ける

メロディの音（1つ1つ）が、そのとき鳴っている和音に対して、どう聞こえるかを、**主音（ドの音）からの半音の数**で判定します。

| 種類 | 色（帯） | 意味 | 係数 |
|---|---|---|---|
| **コードの音** | 緑 | 和音の構成音（7th を足した和音なら、7th も） | +1 |
| **テンション** | 水色 | 9th・11th・13th など、和音に色をつけて、使ってよい音 | +1（さらに、ボーナス。6章） |
| **経過音** | 灰色 | どれでもないが、**短くて弱い拍**なので、通りすぎるだけ。（ぶつかる音でも、短くて弱い拍なら、ここに入る） | 0 |
| **不安定** | 黄色 | どれでもない音が、**長い・強い拍**で鳴る | −0.25 |
| **アヴォイドノート** | 赤 | 和音の構成音の、**半音上**の音（短9度でぶつかって、濁る） | −1 |

（和音がまだ置かれていないステップの音は、白抜きの棒です。）

### 4-1. アヴォイドノートの決め方（半音上の音）
「**和音の構成音のどれかの、ちょうど半音上の音**」を、アヴォイドノートとします（メロディの音と、和音の構成音が、短9度でぶつかる）。この1つの決まりで、ジャズ理論の「アヴォイドノート」が、だいたい出ます。

- 向きは、**メロディが、和音の構成音の半音「上」**のときだけです。メロディが、和音の構成音の半音「下」のとき（例: ⅣM7（ファ・ラ・ド・ミ）の上の「シ」= ♯11th。ドの半音下）は、リディアンの響きとして、テンション扱いにしています（和音の音が、メロディより下にあるので、ぶつからない）。

| 和音 | アヴォイドになる音 | 理由 |
|---|---|---|
| ⅠM7（ド・ミ・ソ・シ） | ファ ／ ド♯ ／ ソ♯ | ファ は ミ の半音上（11th）。ド♯ は ド の半音上。ソ♯ は ソ の半音上 |
| Ⅴ7（ソ・シ・レ・ファ） | ド（11th）／ ファ♯ | ド は シ の半音上。ファ♯ は ファ の半音上 |
| Ⅱm7（レ・ファ・ラ・ド） | ラ♯ ／ レ♯ ／ ファ♯ | ♭13th など |
| Ⅲm7（ミ・ソ・シ・レ） | ファ（♭9th）／ ド（♭13th） | ファ は ミ の半音上、ド は シ の半音上 |
| Ⅵm7（ラ・ド・ミ・ソ） | ファ（♭13th） | ファ は ミ の半音上 |
| Ⅶm7♭5（シ・レ・ファ・ラ） | ド（♭9th） | ド は シ の半音上 |

### 4-2. テンションの表（和音の種類ごと）
ルート（和音の根音）からの半音の数で、決めています。

| 和音の種類 | 使ってよい音（テンション） |
|---|---|
| 長三和音（Ⅰ・Ⅳ・Ⅴ）・M7（ⅠM7・ⅣM7 など） | 9th（+2）・♯11th（+6）・13th（+9） |
| 短三和音（Ⅱm・Ⅲm・Ⅵm）・m7 | 9th（+2）・11th（+5）・13th（+9） |
| ドミナント7th（Ⅴ7・Ⅲ7・Ⅵ7・Ⅱ7・Ⅰ7・Ⅶ♭7・Ⅱ♭7） | 9th・13th・**♭9th・♯9th・♯11th・♭13th**（オルタード。ドミナントでは、使ってよい） |
| m7♭5（Ⅶm7♭5・Ⅳ♯m7♭5） | 9th・11th・♭13th |
| dim7（Ⅴ♯dim7） | 9th・11th・♭13th・7th |
| sus47（Ⅴsus47） | 9th・13th（3度の音は、4度とぶつかるので、アヴォイド） |
| m6（Ⅳm6・Ⅲ♭m6） | 9th・11th |

- **3和音の上の 7th**: 長三和音・短三和音の上で、その調（C メジャー）の音階にある 7th（Ⅰ の上のシ、Ⅴ の上のファ、Ⅵm の上のソ など）は、7th として、テンション扱いにします（和音を 7th にしなくても、メロディの 7th は自然に聞こえるため）。
- 判定の順番: ① 構成音か → ② テンションの表にあるか → ③ 半音上のアヴォイドか → ④ どれでもない（経過音・不安定）。

### 4-3. 例: ⅠM7（ド・ミ・ソ・シ）の上の、12音
| 音 | 判定 |
|---|---|
| ド・ミ・ソ・シ | コードの音 |
| レ（9th）・ラ（13th）・ファ♯（♯11th） | テンション |
| ファ・ド♯・ソ♯ | アヴォイド |
| レ♯・ラ♯ | どれでもない（短く弱ければ経過音、長ければ不安定） |

## 5. 1つの音の「重み」（長い音・強い拍ほど、大事）

重み = **長さ（16分音符いくつぶんか）× 拍の強さ**。

| 拍の強さ | 係数 |
|---|---|
| ステップの頭（和音が変わる瞬間） | ×1.6 |
| 2拍目の頭 | ×1.3 |
| 8分の裏 | ×1.0 |
| 16分の裏 | ×0.7 |
| 前のステップから、のびてきた音（和音が変わっても、鳴り続ける） | ×1.0（新しい和音で、あらためて判定） |

- **経過音（飾り）の扱い**: 8分音符より短く（2マス以下）、拍の頭でない音は、**ぶつかる音（アヴォイド）でも、不安定でも、通りすぎるだけ**とみなします（係数 0）。「長く・強く鳴るアヴォイドだけが、本当にぶつかる」という考え方です。
- 前のステップからのびている音は、和音が変わったあとも判定されます（例: 3番の和音 Ⅳ では「ド」は5度でコードの音。次の 4番が Ⅴ に変わると、のびている「ド」は、アヴォイド）。

## 6. ステップの点・ボーナス・相性・星

- **ステップの点** = そのステップの音の「係数 × 重み」の平均（−1〜+1）× **150**。メロディの音がないステップ（お休み）は、数えません。和音がないステップは 0 点（満点の分には、数えます）。
- **テンションのボーナス +40**: 次の3つがそろったステップ。① 強い拍（頭・2拍目の頭・長い音）の音が、テンション ② そのステップに、アヴォイド・不安定な音がない ③ ステップの平均が 0.8 以上。**1つの盤で、3ステップまで（最大 +120）**。（テンションばかり選ぶことの、行きすぎを防ぐ上限です）
- **相性（%）** = ステップの点の合計 ÷ 満点（150 × メロディのあるステップの数）。マイナスのときは 0%。
- 総得点にも入るのは、「ステップの点の合計 + ボーナス」です。
- **星**（3つの条件。順に満たす）
  - 星1: 相性が **60%** 以上
  - 星2: 相性が **90%** 以上
  - 星3: 星2 のうえで、コード進行の点（技・ジャッジ）が、**お手本の一例の、5割以上**

## 7. 5つのメロディ

どれも、1周 8ステップ。BPM は、ステージの標準（上のバーで変えられます）。駒は、「使える駒」の指定があるものと、ぜんぶ使えるものがあります。

| 番号 | 題 | 学べること | 使える駒 | お手本の一例（1〜8番） | 仕掛け（罠）|
|---|---|---|---|---|---|
| 1 | はじめてのメロディ（BPM 96） | コードの音と、アヴォイド | Ⅰ・Ⅱm・Ⅲm・Ⅳ・Ⅴ・Ⅵm・Ⅴ7・→ | Ⅰ Ⅵm Ⅳ Ⅴ Ⅰ Ⅳ Ⅴ Ⅰ | 3番・6番の長い「ファ」は、Ⅰ の上でアヴォイド（Ⅳ・Ⅱm・Ⅴ が合う） |
| 2 | いろどりのテンション（BPM 88） | 9th・13th などのテンション | 7th の和音を含む（Ⅰ7 まで）・→ | ⅠM7 Ⅲm7 ⅣM7 Ⅴ7 Ⅵm7 Ⅱm7 Ⅴ7 ⅠM7 | 強い拍の 9th・13th。3番・4番・6番・7番の「ファ」 |
| 3 | せつない Ⅵm（BPM 92） | sus4 と、その解決（Ⅴsus47 → Ⅴ7 の加点） | Ⅴsus47 を含む | Ⅵm Ⅳ Ⅴsus47 Ⅴ7 Ⅵm Ⅳ Ⅴ7 Ⅰ | 3番の、長く伸びる「ド」。Ⅴ・Ⅴ7 では、シとぶつかる。Ⅴsus47 なら、コードの音 |
| 4 | ちょっと 寄り道（BPM 100） | ♯のついた音 = ドミナント7th のサイン | ぜんぶ | Ⅰ Ⅲ7 Ⅵm Ⅵ7 Ⅱm7 Ⅱ7 Ⅴ7 Ⅰ | 2番の「ソ♯」・4番の「ド♯」・6番の「ファ♯」 |
| 5 | ほのかな影（BPM 90） | ラ♭の音 = サブドミナントマイナー（Ⅳm）のサイン | ぜんぶ | Ⅰ Ⅵm Ⅳ Ⅳm7 Ⅰ Ⅱm7 Ⅴ7 Ⅰ | 4番の長い「ラ♭」。Ⅳm7 なら満点・Ⅳ だと不安定・Ⅰ ならアヴォイド |

お手本の得点（コード進行の点 + メロディの点。星3 の基準の元になります）: ① 3,760（2,520 + 1,240）② 2,296（976 + 1,320）③ 2,340（1,140 + 1,200）④ 2,003（803 + 1,200）⑤ 2,100（900 + 1,200）。

- **お手本は、正解ではありません**。合う和音は、1つとは限りません（たとえば、1番の「ミ・ソ」には、Ⅰ・Ⅵm・Ⅲm・Ⅳ・Ⅴ など、ぶつからない和音がいくつもあります）。
- 「1つの和音だけを、8つ並べる」やり方では、相性は **47〜63%** にしかなりません（星は 0〜1。メロディの長い音が、そのコードと、ぶつかるように作ってあるため）。

## 8. メロディのステージの、ヒント
ヒントを ON にすると、次に置く場所（左から最初の空き）について、**メロディとの相性を考えた候補**が出ます（物理的な盤でない時は、候補の札をクリックすると置けます）。

- メロディとぶつかる和音（相性 0.5 未満）は、**候補から外します**。
- メロディによく合う（0.8 以上）候補は、順位を上げて、理由に「メロディ: ミ・ソ が コードの音、レ が 9th（テンション）」のように、**メロディとの関係**が付きます。
- コード進行の理由がなくても、メロディにとてもよく合う（0.85 以上）、この調の音だけでできた和音は、「メロディに合う: …」として、発展に出ます。
- 自動テストで、5つのメロディ × 8か所について、「出たヒントは、いつもメロディとぶつからない」ことを確かめています。

## 9. 画面の見方
- **帯**（画面の上の真ん中）: 8つの列 = 盤の1〜8番。棒の高さ = 音の高さ、長さ = 音の長さ。列の下に、置いてある和音（駒の働きの色）・評価（◎ ○ △ ×）・そのステップの点。いま鳴っているステップは、黄色い線で出ます。
- **列をクリック**: 右の「理由」の欄に、そのステップの音の聞こえ方（「ミ」は Ⅰ の3度（コードの音）…など）が出ます。棒にマウスを置くと、その音の説明が出ます。
- **右の「メロディ +765」**: いまのメロディの点。帯の上にも、相性（%）と点が出ます。
- **左のガイド**: 色の凡例と、このメロディのポイント。
- 盤は、帯の場所をあけるため、少し小さく・下へ下がっています。

## 11. 限界・まだ確かめていないこと・あなたに決めてほしいこと

### 確かめたこと（自動テスト・パソコン上）
- 音の分類 **約 70 通り**が、表どおり（ⅠM7・Ⅰ・Ⅴ7・Ⅴ・Ⅱm7・Ⅲm7・Ⅵm7・ⅣM7・Ⅶm7♭5・Ⅴsus47・Ⅳm7・Ⅲ7）／ 採点（お手本は満点、ぜんぶ Ⅰ だと下がる、空き・休み・「→」・のびている音・ボーナスの上限）／ 5つのメロディのデータ（長さ・音域・お手本・罠）／ 星の条件／ ヒントが、いつもメロディとぶつからない／ メロディの音（時刻・長さ・高さ・大きさ）／ 画面の操作（本物のマウスで駒を置いて、帯の色・点・結果が変わる）。

### まだ確かめていないこと
1. **耳で聴いて、メロディの音色・音の大きさ・ぶつかる音が、納得できるか**（メロディの音は、笛のような合成音。数値の検査のみです）。
2. **点数のバランス**。いまは、メロディの満点（1,200）と、コード進行の点（お手本で 800〜2,500）が、同じくらいの重さです。進行の点が大きくなる盤では、相性の影響が小さく感じるかもしれません。
3. 実機の盤で遊んだときの手応え（実機の盤のときも、画面の上の帯は、実機の駒をそのまま採点します）。
4. メロディの出来（わたしが、音楽理論から作ったオリジナル）。「もっとこういう曲がいい」があれば、直せます。

### 解釈で、あなたに確かめたいこと（わたしの仮の判断）
- Ⅰ の上の **ファ♯（♯11th）をテンション**にしたこと（リディアンの響き）。「ドレミの外の音は、Ⅰ の上では、アヴォイドにしたい」なら、表から外せます。
- ドミナント7th では、**♭9th・♯9th・♯11th・♭13th（オルタード）を、ぜんぶ「使ってよい」**にしたこと（ジャズの定番ですが、メロディによっては、広すぎるかもしれません）。
- **3和音の上の 7th（Ⅴ の上のファなど）を、テンション扱い**にしたこと。
- **短くて弱い拍のアヴォイドは、許す**こと（長く・強く鳴るときだけ、ぶつかる）。
- ボーナスを、**強い拍のテンション（濁りなし）**にだけ与えること、上限が3ステップであること。
- 依頼の「コードトーンが、メロディに対するアヴォイドノートになっていないか」を、「**メロディの音が、和音の構成音と、短9度（半音）でぶつかっていないか**」と読みました（4-1）。「和音の構成音のほうが、メロディの半音上にある」向きは、アヴォイドにしていません（上の注）。読み方が違っていたら、教えてください。
