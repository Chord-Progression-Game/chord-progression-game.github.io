# 11/18（水）ゼミの、デモの進め方

目的: 先生に言われた「**ゲームフローややらせたい体験が、視覚的・感覚的に分かるプロトタイプ**」を、7分くらいで見せる。
持っていくもの: Mac（電源つき）・イヤホンまたはスピーカー・（あれば）実機の盤と USB ケーブル。ネットは要らない。

## 前の日までに（15分）

1. `sh tools/game.sh` で、Chrome が開く → 「はじめる」をクリック → タイトルで、背景の盤が自動で進行を鳴らす（音が出る）。
2. 音量を決める（Mac の音量・イヤホン / スピーカーの切り替え）。**耳で聴いて、音の良し悪しを確かめてください**（私は、耳では確認できません）。
3. タイトルの「**ぜんぶ開く（デモ用）**」で、全ステージを開いておく（鍵が外れて、好きなステージから始められる）。
   - 「はじめての人の体験」を見せたい → 先に「進み具合をリセット」してから「ぜんぶ開く」（技が決まるたびに NEW が出て、図鑑が増えていく）
   - 「図鑑がたくさん光った状態」を見せたい → 前の日に、フリープレイで、いくつか技を決めておく（進み具合は、このブラウザ・このポート番号（8800）に保存される。別のブラウザ・別のパソコン・別のポート番号では、引き継がれない）
4. プロジェクターなど外のディスプレイにつなぐなら、つないだ状態で一度、開いてみる（1920×1080 では確認済み。画面はウィンドウに合わせて拡大縮小される）。
5. 実機の盤を見せるなら、**必ず一度リハーサル**する。本物の ESP32 とゲームの接続は、まだ確認できていない（ニセの ESP32 での確認のみ）。うまくいかなければ、画面の盤だけで、全部見せられる。

見せ方のコツ:
- 技が決まった瞬間（スタンプ・囲み・光）は、**少し待って**見てもらう（約3秒）。
- デモ中は、**このタブを前面に**出しておく。タブが裏に回ると、ブラウザが処理を遅くするので、音が途切れるかもしれない（私は、確かめていません）。

## 先生に、聞きたいこと

1. **技の解釈**（`docs/tricks_spec.md` の8章）。とくに「終止は、フレーズの終わり（4番・8番、または、その後に駒がない）で成立」「固有進行は、1番か5番から」「冒頭（1番）のドミナント系の駒は『？』で −100（5番は減点しない）」「バックドア進行は終止の仲間」「ループのつなぎ目（8番 → 1番）の進行系の技を加点」「偽終止にⅥ♭M7 を含めるか」「ピカルディ終止（2026-11-18 に、Ⅵm で終わるところを Ⅵ 長三和音で終える定義に直した）の直前の和音」（ラグタイム・バックドアの扱いは、第5弾でご回答をいただいて反映した。`docs/theory_audit.md` の4章）。
2. **得点の基準**（先生のメモの「得点の基準がないとモチベーションがない」）。いまは「技の点 × コンボ × 種類」。目標点（パー）を、ステージごとに出す案がある。
3. 方向性: **3D の見た目は、このまま（Web）で十分か**。Unity にする必要があるか。
4. 展示（卒展）では、**実機の駒**で遊ばせるか、画面で遊ばせるか。
5. 対戦モード・ランキング・「誰かに聞かせたい」を、どこまで作るか。
6. **ジャッジ（`docs/judge_report.md`）**: 「進行感のない並びを減点してよいか」「借用和音（サブドミナントマイナーなど）を、どこまで加点するか」「点数の基準は、先生の耳に合うか」。
8. **メロディをつける・書く（`docs/melody_studio.md`）**: 「テンションは 9th まで」の解釈（強い拍・長い音 = コードの音と 9th。9th は音階の中か、ドミナント7th だけ）は、先生の理論と合うか / 自動メロディの「センス」（ルール + 360通りから選ぶ）をどう評価するか / フリープレイの得点に、メロディとの相性を入れるか。
7. **メロディにコードをつける（`docs/melody_mode.md`）**: 「アヴォイドノート・テンションの判定の決め方（11章）は、先生の理論と合うか」「メロディとコード進行の点の、重さのバランス」「メロディは、5つで足りるか・どんな曲調がよいか」。

## うまくいかないとき

| 症状 | 見ること |
|---|---|
| 音が出ない | SPLASH をクリックしたか / 画面右上が「音 ON」か / Mac の音量と出力先 / M キーで ON/OFF が切り替わる |
| 動きが重い | 他のアプリ・タブを閉じる / ウィンドウを小さくする（3D の描画が軽くなる） |
| 画面が真っ白・止まった | F5 で読み込み直す（進み具合は、保存されている） |
| 実機がつながらない | 「盤 画面」のままで続ける。ブリッジが動いているか / USB ケーブルを確認 |
| 駒が置けない | 実機に切り替わっていると、画面の駒の置き場は隠れる。「盤」ボタンで「画面」に戻す |
| 実機の駒が、ときどき消える・認識されない | 駒の位置・向きを直す / `curl -X POST -H 'Content-Type: application/json' -d '{"action":"rstat"}' http://127.0.0.1:8765/api/control` でリーダーごとの統計を出して（結果は `~/Library/Logs/chordtoy_bridge.log`）、「乱れ」「読めなかった」が多いリーダーを見る（CLAUDE.md の 2026-11-16 の節） |
