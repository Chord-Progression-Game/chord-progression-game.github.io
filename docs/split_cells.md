# 分割したマス（1つのマスに、前半・後半の2つのコード）の仕様（2026-11-23）

> ご依頼: 「1つのマスを分割して、2つのコードを置けるようにしたい。すでにあるコマの左側あるいは右側にカーソルを合わせてコマを置くと、そのマスの前半1拍分あるいは後半1拍分が新しく置いたコマになり、通常の半分の長さでコードが切り替わる」

## 1. 操作

- 1つのマス = 2拍（1ステップ）。分けると、**前半（1拍目）・後半（2拍目）**が、別のコードになります。盤の上では、**前半が左・後半が右**の、半分の大きさの駒になります。
- **駒のあるマスの左がわ・右がわに、駒を重ねる**（トレイからドラッグして落とす / クリックで選んで、盤をクリックする / 指でタップする）:
  - **左がわ** → 新しい駒が前半・もとの駒が後半（`[新 | 旧]`）
  - **右がわ** → もとの駒が前半・新しい駒が後半（`[旧 | 新]`）
  - **まん中**（マスの中心から、幅の約 1/3）→ これまでどおり、置きかえ（分割は、なくなる）
  - 空きのマスは、左右に置いても、分けません（そのマスに置く）
- すでに分けたマスは、中心の左・右で、前半・後半が決まります（まん中の置きかえは、なし）。左に置くと前半が、右に置くと後半が、置きかわります。前半と後半が同じ駒になるなら、1つに戻ります。
- 置こうとしている間（ドラッグ中・駒を選んでいる間）は、盤の上に、**透けた半分の駒**が、左右どちらに入るかを見せます。
- **はずす**: ダブルクリック（ダブルタップ）・Delete・駒を盤の外へドラッグ → **指した側の半分だけ**が外れて、**残った半分が、マスぜんたいに広がります**。右クリック（長押し）のメニューも、指した側の駒です。
- **動かす**（盤の駒をドラッグ）: 分けたマスでは、**指した側の半分**を持ち上げます。落とす先は、空きのマス（1つの駒として置く）・駒のあるマスの左右（そのマスを分ける）・まん中（置きかえ）。同じマスの反対側に落とすと、前半と後半が入れかわります。分けていないマスどうしの、空きへの移動・入れ替えは、これまでどおりです。
- **使えるモード**: フリープレイ・タイムアタック・チャレンジステージ。**チュートリアル・メロディーにコードをつける・タイトルのデモ・実機の盤**では、分けません（左右に落としても、置きかえになります）。
- 「→」（前と同じ）は、分けられません。「→」のあとの「→」は、分けたマスの**後半**のコードを、のばします。

## 2. 音

- 分けたマスは、**2拍目の頭で、後半のコードに切りかわります**。ボイスリーディング（前のコードに近い高さ）は、前半 → 後半 → 次のマス、とつながります。
- バッキングは、前半の音を、**2拍目の頭で切ります**（後半のコードに、かぶらないように）。パターンに、2拍目の頭の音がないとき（ロングなど）は、**前半に鳴らした音（和音・ベース・…）を、後半のコードで鳴らし直します**（そうしないと、後半が無音になるため）。2拍目にも音があるパターン（8分のアルペジオなど）は、パターンの音が、そのまま、後半のコードで鳴ります。
- ドラムは、分割に関係なく、そのままです。

## 3. 判定（技・ジャッジ・ヒント）

- マスの中の、前半 → 後半 も、1本の「つながり」として、数えます（例: 前半 Ⅱm7・後半 Ⅴ7 = ドミナントモーション）。後半 → 次のマスの駒 も、つながりです。
- 位置の決まりは、次のとおりです。
  - **名前のついた進行**（王道進行など）は、**1番・5番の頭（前半）**から始まっているとき。後半からは、始まりません。
  - **終止**（Ⅴ-Ⅰ終止など）は、**フレーズの終わり（4番・8番）の、いちばん最後のコード**で決まります。4番が分かれているなら、後半が、4番の終わりです（前半では、終止になりません）。
  - **冒頭（1番）のドミナント「？」**は、1番の**前半**だけが対象です（後半は、冒頭ではありません）。
  - ジャッジの「解決」も、同じ（マスの終わり = 後半）。
- ヒントは、分けたマスの**後半**を、「前の駒」として、つなげます。
- 得点は、分けたぶんだけ、技の候補が増えますが、**分割そのものの加点・減点は、ありません**（遊びながら、様子を見て決めます）。

## 4. 保存・プリセット

- プリセットにも、分割が入ります（`preset.half`: 後半のコードの名前の並び。分割がないプリセットには、付きません）。呼び出すと、分割も戻ります（分けられないモードでは、前半だけ）。分割だけが違うプリセットは、別のプリセットです。保存の画面の、8つのマスには、「前半／後半」と出ます。
- 実機の盤（本物の駒）には、分割がありません。実機の駒が変わったマスは、分割をやめます。

## 5. 限界・まだ確かめていないこと
