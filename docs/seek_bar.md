# シークバー（演奏の位置・巻き戻し・早送り）

2026-11-25 に追加。ご依頼（要約）:「2個目のマスに駒を置いているとき、演奏が4個目のマスあたりにあると、1周回ってくるのを待たなくてはいけない。シーケンスに同期したシークバーを作って、DJ のように巻き戻せるようにしたい。位置は、上の設定ボタンの領域の、中央真下。動かすと、動かした分だけ、DJ の巻き戻し音のような音が鳴る（動かして止めている間は無音）。iPhone の縦画面でも、自然に置く」。

## 1. できること

- 上のバーのすぐ下の真ん中に、**8つに区切った帯**（1〜8番）が出る。演奏に合わせて、左から右へ**線が動く**（8番のあとは、1番へもどる）。いま演奏しているステップの数字は、差し色になる。
- 帯を**つかんで動かす**と、演奏の位置が動く（左 = 巻き戻し・右 = 早送り）。
  - つかんでいる間は、**演奏が止まる**。巻き戻しの音（下の 4 章）だけが、動かした分だけ鳴る。**動かさずに止めている間は、無音**。
  - **はなすと**、その位置から続きを演奏する（約 0.05 秒あと）。
  - 帯の**途中を押す**と、そこへ飛ぶ（短い「ひゅっ」という音。飛んだ距離が長いほど、少し長い）。
  - はなした位置が、ステップの頭に **2マス（8分音符）以内**なら、頭に吸いつく（1番の頭へ巻きもどしやすいように）。周回の終わりに近ければ、1番の頭。
- 3D の盤の「いま」の印と、光る駒が、つかんでいる位置についてくる。メロディのステージでは、メロディの帯の線も同じ位置を指す。
- **演奏を止めている間は、帯は薄くなって、使えない**（スペースで演奏を始めると、使える）。
- キーボード（帯にフォーカスがあるとき）: ← → で 1ステップ・Home で 1番の頭・End で 8番の頭。
- チュートリアルで、駒が4つ以内のとき（4ステップでループ）は、区切りが **4つ**になる。

## 2. 位置の考え方（`js/audio/engine.js`）

- 1マス = 16分音符。1ステップ = 8マス（2拍）。1周 = 8ステップ = 64マス（4ステップのときは 32マス）。
- `loopPosAt(t)` が、時刻 t の演奏の位置 `{ pos（周回の何マス目か。小数）, len }` を返す。周回の始まりの記録（`_loops`）から求めるので、4ステップ・8ステップの切りかえにも合う。画面は、出力の遅れ（`outputLatency`）のぶん前の時刻で聞く（耳に届いている位置）。
- `loopSlotAt(t)` は、その `pos`（メロディの帯・メロディの画面の線が使う）。

## 3. つかんでいる間・はなしたあとの、エンジンの動き

| 関数 | 動き |
|---|---|
| `scrubBegin(fromPos)` | 演奏中だけ、つかめる。鳴っている音（予約ずみのものも）を、すっと消す（`_cutSession`）。これから来るはずの、ステップ・拍の知らせは捨てる。演奏を進めない（`_tick` が何もしない）。巻き戻しの音の部品を作る |
| `scrubTo(pos, nowMs)` | つかんでいる位置を動かす。動かす速さ（マス/秒。向きつき。少しなめらかに）を、巻き戻しの音に伝える。遠くへ飛んだときは、距離ぶんの長さの「ひゅっ」 |
| `scrubTick(nowMs)` | 毎フレーム。動かしていない間は、速さを 0 に近づける（約 0.06 秒の減り方）→ 音が消える |
| `scrubEnd(pos, {snap})` | はなす。位置をまるめて（吸いつき）、`_applySeek` で続きを予約する |
| `seekTo(slot)` | つかまずに動かす（キーボード・テスト用） |

**途中から続けるとき**（`_applySeek` → `scheduleSlot` の最初のマス）、ふつうに演奏していれば鳴っているはずの音を、つづきから鳴らす:
- そのステップのコード（分割したマスの後半なら、後半のコード）を、先に決める。ステップの途中から始めたときは、画面への知らせに `seek: true` が付く（技の「きらっ」は鳴らさない）。
- バッキング: 直前に始まった音が、パターンの「-」でのびていて、まだ終わっていなければ、残りの長さで鳴らす（`_carryAt`）。スタッカートの音（`C...` など）は、もう終わっているので、鳴らさない（ふつうの演奏と同じ）。分割したマスの後半は、後半の頭の「鳴らし直し」も、同じ。
- ドラム: 動かした位置のパターンから（位置がずれない）。
- メロディ: のびている音を、残りの長さで。
- 続きの演奏が始まる前の約 0.05 秒は、位置の表示を、はなした位置に止めておく（`_seekHold`。印が、一瞬、後ろにもどらないように）。

## 4. 巻き戻しの音（`js/audio/scrub.js`）

合成音（録音ではない）。**風切り音**（帯域をしぼったノイズ）+ **テープの回る音**（のこぎり波。±28 セントのゆれ）。つかんでいる間だけ部品がある。専用のバス（`scrubBus`。リバーブなし。全体の音量・ミュートは効く）。

- 速さ = 動かしている速さ ÷ 通常の演奏の速さ（BPM 120 で 8マス/秒）。0.04 倍より遅ければ、無音。
- 大きさ: `0.34 × (1 − e^(−速さ/1.2))`。ゆっくり（0.5倍）でも聞こえ、いちばん速く（30倍）しても、和音の試聴と同じくらい。
- 高さ: 速いほど、高く・するどく。風切り音の帯域 450〜4650Hz・のこぎり波 180〜1620Hz。向きで、のこぎり波が少し変わる（巻き戻し ×0.85・早送り ×1.25）。
- 指のふるえ（1.5px 未満の動き）は、動きに数えない（止めているときに鳴らない）。

## 5. 置き場所（`css/game.css`・`css/mobile.css`・`js/ui/layout.js`）

| 画面 | 位置 |
|---|---|
| PC | 上のバーの 0.3rem 下・画面の真ん中・幅 34rem（左のガイド・右の得点の欄のあいだ）。技のスタンプ・メロディの帯は、その下に下がる。3D の盤も、技のラベルがバーにかからないぶん（約 16px）下がる（`scene.setTopInset`）。メロディのステージでは、メロディの帯と同じ幅で、8つの区切りが、帯の8つの列とそろう |
| スマホ縦（幅 900px 以下） | 上のバーの下の、画面いっぱいの1行（見える帯 1.9rem・指でつかめる範囲 2.6rem）。得点・手順の帯・技のスタンプ・盤の見える範囲は、その下 |
| スマホ横（高さ 520px 以下） | 上のバーの下。左のガイド（開いているときは、その右）と、右の得点の列のあいだ（見える帯 1.8rem + 上下に広げた、つかめる範囲）。盤の見える範囲が、そのぶん狭くなる |

CSS 変数 `--seek-h`（帯が使う高さ。PC 2rem・縦 2.8rem・横 2.2rem）で、下の部品の位置を決める。

## 9. 確認したいこと（ユーザーへ）

1. 巻き戻しの音の聞こえ方（DJ の巻き戻しらしいか・大きさ・高さ）。数字は `scrub.js` の `scrubParams` と `AMP_MAX`。
2. はなしたとき、ステップの頭に **2マス以内なら吸いつく** のは、ほしい動きか（吸いつかない・もっと広い、にもできる。`SNAP_SLOTS`）。
3. 演奏を止めている間は、帯を使えなくした。止めたまま位置だけ動かして、そこから再生、にしたいか。
4. スマホ横持ちのメロディのステージは、もともと盤が小さい。バーのぶん、さらに少し小さくなった。
