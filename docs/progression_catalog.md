# 名前のついた有名な進行の一覧（調べた結果）

> **2026-11-18 第5弾の更新**: バックドア進行は「終止」の仲間（フレーズの終わりで成立。どの位置からでも）。ラグタイム進行は「冒頭（1番）から Ⅰ を2つぶん以上」。

- 作成: 2026-11-15 ／ ゲームへの実装: `game/js/core/tricks.js`（技の定義・点数は、**このファイルだけ**）。ルールは [tricks_spec.md](tricks_spec.md)。
- あなたの依頼: 「この世界に多数存在している、名前の付いた有名な固有の進行を調べ上げて、私に見せるリストを作って追加してください」
- **固有進行のルール**（あなたが決めたもの）: 名前のついた決まった並びは、**1個目か5個目のコードから始まっていないと成立しない**。（例: 2・3・4個目にたまたま Ⅵm・Ⅳ・Ⅴ が並んでも、小室進行にはならない）
- 度数は、Key=C のときのコード名を並べて、書いた。判定は度数で行うので、Key を変えても同じ。

**確かさの印**（調べ方: ウェブで検索して、記事を読んだ。私は耳では確認できない）
- ◎ 複数の資料、または信頼できる解説（Wikipedia・新聞社系の解説サイトなど）で、並びを確認できた
- ○ 資料はあったが、個人の解説・まとめサイトが中心（並びは確認できたが、名前の使われ方に揺れがありうる）
- △ 一般に知られているが、今回の調査では、並びや名前の裏づけを取れなかった（使うなら、要確認）
- ※ ゲームに入れた名前・並びは、下の「実装」の列。あなたが「この名前・並びは違う」と思ったら、教えてください（直すのは `tricks.js` だけです）

## 2. ゲームに入れた「終止」（4個）と「つながり」（3個）

終止は、**フレーズの終わり**（4番か8番の駒。または、その後に続く駒がないとき）で成立します。

| 仲間 | 名前 | 並び | 点 | 確かさ |
|---|---|---|---|---|
| 終止 | Ⅴ-Ⅰ終止（正格終止） | Ⅴ・Ⅴ7・Ⅴsus47 → Ⅰ・ⅠM7 | 200 | ◎ |
| 終止 | ドミナント終止（半終止） | Ⅰ系・Ⅵm系・Ⅳ系 → Ⅴ系 | 150 | ◎（Ⅴで終わる終止を「半終止」という。「句点でなく、読点のようなもの」） |
| 終止 | **ピカルディ終止**（2026-11-18 に作り直し） | Ⅲ7・Ⅴ系・Ⅱm系・Ⅵm系・Ⅵsus4 → **Ⅵ（長三和音）** | 250 / 300（サスつき） | ◎（「短調の楽曲の最後が、短三和音の主和音でなく、長三和音で終わること」。イ短調の Am → A。ゲームの主音は長調なので、短調の主和音は Ⅵm。くわしくは [theory_audit.md](theory_audit.md)） |
| 終止 | **偽終止**（2026-11-16 に変更） | Ⅵm・Ⅵm7 で終える（前は何でもよい）。Ⅴ・Ⅴ7・Ⅴsus47 のあとなら +50（Ⅵ♭M7 でもよい） | 200 / 250 | ◎（「Ⅰの代わりに別の和音が用いられる正格終止。最もよく見られるのは Ⅴ→Ⅵ」。「Ⅵで終えれば、前は問わない」は、あなたの指定） |
| つながり | ドミナントモーション | ルートが完全4度上へ（強進行・セカンダリードミナント・ツーファイブワン） | 100 / 150 / 400 | ◎ |
| つながり | 弱進行 | ルートが完全5度上へ | 60 | — |
| つながり | 半音下への進行（裏コードを含む） | ルートが半音下へ | 120 / 350 | ◎（裏コード: Ⅱ♭7→Ⅰ） |

## 3. 調べたけれど、いまは入れなかったもの

入れなかった理由は、「盤に入らない」「いまの駒の表にない」「名前の裏づけを取れなかった」「すでに技になる」のどれか。**入れてほしいものがあれば、教えてください**（駒の表にあるもの・並びが分かっているものは、すぐ足せます）。

| 名前 | 度数 | 入れなかった理由 | 確かさ |
|---|---|---|---|
| 12小節ブルース | Ⅰ Ⅰ Ⅰ Ⅰ Ⅳ Ⅳ Ⅰ Ⅰ Ⅴ Ⅳ Ⅰ Ⅴ | 12個で、盤（8つ）に入らない。8小節ブルースで代用した。（駒の表に Ⅳ7 もない） | ◎ |
| 16小節ブルース | Ⅰ×8 Ⅳ×2 Ⅰ×2 Ⅴ Ⅳ Ⅰ×2 | 16個で、盤に入らない | ◎ |
| 逆循環 | Ⅲm7→Ⅵ7→Ⅱm7→Ⅴ7（と言われる） | 今回の検索では、名前の使われ方を確認できなかった | △ |
| サークル進行（Circle progression） | Ⅵm→Ⅱm→Ⅴ→Ⅰ | 「ツーファイブワン + 強進行」として、すでに技になる。小室進行の変形 Ⅵm→Ⅱm→Ⅴ→Ⅰ と同じ並び | ◎ |
| Montgomery–Ward ブリッジ | Ⅰ→Ⅳ→Ⅱm→Ⅴ | Wikipedia の一覧にあるが、よく知られた名前ではない | ◎ |
| ポップパンク進行の並べ替え | Ⅵm→Ⅳ→Ⅰ→Ⅴ ／ Ⅳ→Ⅰ→Ⅴ→Ⅵm ／ Ⅴ→Ⅵm→Ⅳ→Ⅰ | 呼び名が資料によって揺れる。（Ⅴ から始まるものは、1番・5番に Ⅴ が来て、「？」になる） | ○ |
| ルイルイ進行（Louie Louie） | Ⅰ→Ⅳ→Ⅴ→Ⅳ | 日本語で定着した名前を、確認できなかった | △ |
| Ⅰ→♭Ⅶ→Ⅳ ／ ♭Ⅵ→♭Ⅶ→Ⅰ ／ Ⅰ→♭Ⅶ→♭Ⅵ→♭Ⅶ（ミクソリディアン系・ロック終止） | — | ♭Ⅶ・♭Ⅵ の**長三和音**の駒が、表にない（Ⅶ♭7・Ⅵ♭M7 はある） | ◎ |
| ナポリ（Ⅱ♭M7→Ⅴ7→ⅠM7） | Ⅱ♭→Ⅴ→Ⅰ | 駒（Ⅱ♭M7）はある。「ナポリの六」の名前・並びの裏づけを、今回は取れなかった | △ |
| ライン・クリシェ | Ⅵm→Ⅵm(M7)→Ⅵm7→Ⅵm6 など | 分数コード・m(M7) の駒が、表にない | ◎ |
| 変格終止（アーメン終止） | Ⅳ→Ⅰ | 終止の追加は、「偽終止」だけと理解した。いまは、ふつうの「弱進行」になる。**足すなら、すぐできる** | ◎ |
| フリジア終止 | ♭Ⅵ→Ⅴ（など） | ♭Ⅵ の三和音の駒が、表にない | ○ |
| パッサメッツォ（アンティコ・モデルノ）・ロマネスカ・フォリア | 9〜17個の和音 | 盤に入らない。ルネサンス・バロックの定型で、短調が前提 | ◎ |
| Bird changes・Coltrane changes・Rhythm changes | 15〜20個 | 盤に入らない。駒の表にもない和音がある | ◎ |
