## 1. 読み方

| 言葉 | 意味 |
|---|---|
| 度数 | Ⅰ = 主音（Key の C など）。判定は度数で行うので、**Key を変えても結果は同じ** |
| 位置 | 盤の 1〜8 番。1〜4 が奥の段、5〜8 が手前の段。演奏は 1→8 の順で、ループする |
| フレーズ | **4つの位置で1まとまり**（1〜4番・5〜8番）。「小節の頭」= **1番と5番**。「フレーズの終わり」= **4番と8番** |
| 休み | 空きの位置。**つながりが切れる**（前後は、つながらない） |
| 「→」の駒 | 前のコードを、もう1つ分のばす（位置が増えるだけで、コードは増えない）。固有進行でも、つなぎ目は無視する（Ⅵm → Ⅳ Ⅴ も、小室進行） |
| ルートの動き | 次のコードのルートが、上へ何半音か。完全4度上 = 5、完全5度上 = 7、半音下 = 11 |

## 3. 冒頭（1番）のドミナント系の駒 = 「？」（技にならない・コンボなし・100点の減点）

- **1番**に、ドミナント系の駒が置かれると、「？」と、不自然であることを知らせる（画面: 駒の囲みに「？ 冒頭のドミナント −100」、スタンプ、技の一覧、WHY の説明、小さな効果音）。
- ドミナント系の駒 = **Ⅴ系**（Ⅴ・Ⅴ7・Ⅴm7・Ⅴsus47）・**ドミナント7th**（Ⅰ7・Ⅱ7・Ⅲ7・Ⅵ7・Ⅶ♭7・Ⅱ♭7）・Ⅴ#dim7・**Ⅵ（長三和音）**。（2026-11-18 のご指示: 冒頭の Ⅲ7・Ⅰ7 も、Ⅴ と同じ −100）
- **5番は、減点しない。**（以前は 1番・5番だった。「減点は冒頭（1番）だけ」というご指示）
- その駒は、**どの技にも使われない**（前後のつながりも、技にならない）→ **コンボもとれない**。ドミナントモーションの得点を狙って、冒頭にドミナントを置くのを、防ぐ。
- 得点から **100点を引く**。**0点より下にはならない**。
- 「→」でのばしただけの位置は、「？」ではない。
- **例外（減点しない形）**: ① **ラグタイム進行**（Ⅲ7 → Ⅵ7 → Ⅱ7 → Ⅴ7 のあと、Ⅰ を2つぶん以上）② ドミナントが4度ずつ上がって連なり、最後が Ⅴ系で、Ⅰ・ⅠM7 に着いて2つぶん以上のばす形（Ⅴ7 → Ⅰ →、など）③ **8小節ブルース**（Ⅰ7 から始まる形）。ドミナントが連なっても、Ⅰ にしっかり着くなら、冒頭から始めてよい、という解釈。
- 理由: ドミナントは「次へ進みたい」響き。冒頭に置くと、落ち着かず、不自然に聞こえる。

## 4. 判定のルール

1. **隣り合う2つのコードの「つながり」**（休みでは切れる）を見て、技を探す。3つ・4つ・5つ・8つの並びで決まる技も、同じつながりを順に見る。
2. **1つのつながりは、1つの技だけが取る。** 長い技・特別な技ほど優先（下の「優先度」）。囲みが重ならず、点を二重に数えない。
3. 優先度が同じなら、**左（小さい位置）から**、**長いものから**取る。
4. 隣り合う技が、**駒を1つ以上共有してつながる**と「コンボ」。同じ種類の技の繰り返しは点が下がり、種類が多いと倍率が上がる（6章）。
5. **ループのつなぎ目（8番 → 1番）**: 盤が8つぜんぶ使われていて、**8番の駒と 1番の駒が、休みでなくつながる**とき、進行系の技（強進行・セカンダリードミナント・ツーファイブワン・弱進行・半音下・裏コード）が成立する（2026-11-18 追加）。7番 → 8番 → 1番 の3つで決まるツーファイブワンは、ふつうの強進行を置きかえる（点が上がる）。**終止・固有進行は、つなぎ目をまたがない**。つなぎ目の技は、単独（コンボなし）で、囲みは 8番と 1番の両方。理由に「ループして…」と出る。
6. 技にならなかったつながりは、性質（ルートの動き・共通音の数・色の濃さ）で**描写**する（画面の「オリジナル」。この描写では、点は変わらない）。そのうえで、**ジャッジ**（6-4章）が、耳に馴染む並びを加点、進行感のない並びを減点・指摘する（2026-11-16 に追加）。

**優先度（高いほうが先に取る）**: 100 王道進行 ＞ 98 丸サ進行 ＞ 96 ブルース ＞ 95 カノン進行 ＞ 92 ラグタイム・循環コード・50年代・ポップパンク・アンダルシア・カデンツ ＞ 90 小室 / Ⅳ-Ⅲ-Ⅵ / Ⅳ-Ⅴ-Ⅵ / バックドア ＞ 85 ツーファイブワン ＞ **82 サブドミナントマイナー（Ⅳ→Ⅳm→Ⅰ）** ＞ 80 終止（Ⅴ-Ⅰ・ピカルディ・偽終止・ドミナント終止）＞ **77 ネアポリタン進行** ＞ **75 借用和音（Ⅳm系・代理 → 自然な着地）** ＞ 70 裏コード ＞ 60 ふつうの強進行 / 弱進行 / 半音下

## 6. 得点（点数は仮。遊びながら調整する）

```
盤の得点 = ( Σ 各技の点 × 繰り返し × コンボ ) × 種類の多さ − 「？」の減点（100点ずつ。0点より下にはならない）
繰り返し   同じ「種類」の、1回目 ×1 / 2回目 ×0.6 / 3回目 ×0.4 / 4回目 ×0.3 / 5回目以降 ×0.2
コンボ     つながった技の数 1つ=×1 / 2つ=×1.5 / 3つ=×2 / 4つ=×2.5 / 5つ以上=×3
種類の多さ 違う種類が1つ増えるごとに +10%
```

- 「同じ種類」は、**技の種類（図鑑の1つ）の単位**。セカンダリードミナント・ツーファイブワン・強進行は、同じ「ドミナントモーション」。裏コードと半音下も、同じ「半音下への進行」。
- 得点は「**いま盤の上で決まっている技**」の合計。駒をはずすと、その技の点がなくなるだけ（何度でも組み替えられる）。
- チャレンジは、90秒のあいだの**最高点**を採用。★は 500 / 1000 / 1800（仮）。

### 6-2. コードの難しさの加点（2026-11-16 に追加）

盤の上の「**ちがう駒**」ごとに、**1回だけ**、レベルに応じた点が入る（技にならなくても入る。「→」と「？」の駒は、数えない）。

```
レベル     1    2    3    4    5
加点       0   +10  +20  +30  +40
盤の得点 = ( Σ 各技の点 × 繰り返し × コンボ ) × 種類の多さ + コードの難しさの加点 − 「？」の減点
```

- ヒントの順位には、この加点を使わない（高いレベルの駒ばかり、勧めないように）。

## 8. 確認してほしいこと（私の解釈）

1. **終止は「フレーズの終わり」だけで成立**にした（あなたの指示: 「その後に続くコードがないか、4個目もしくは8個目のコードに、Ⅰ度・Ⅴ度・Ⅵ度のコードが来ると成立」）。私は、**「終止の最後の駒が 4番か8番に着いている」か「その後に、続く駒がない（休みか、盤の終わり）」と読んだ**。「その後に続く駒がない」には、**休み（空き）で区切られている場合**を含めた。違うなら教えてください。
2. **ドミナント終止の「小節頭が Ⅰ・Ⅵm・Ⅳ 系」** は、以前は「2つの位置の小節の頭」で判定していたが、今回の「小節 = 4つの位置」の考えと合わなくなったので、**「Ⅴ の直前の駒が、Ⅰ系・Ⅵm系・Ⅳ系」** に読み替えた（位置は、フレーズの終わりの判定だけ）。Ⅳ系 = Ⅳ・ⅣM7・Ⅳm7・Ⅳm6、Ⅰ系 = Ⅰ・ⅠM7、Ⅵm系 = Ⅵm・Ⅵm7。
3. **「？」の駒は、技に一切使わない**（前後のつながりも、技にならない）と解釈した。（たとえば 4番 Ⅱm7 → 5番 Ⅴ7 は、「Ⅱ→Ⅴ」のつながりも、技にならない）
4. **偽終止の Ⅵ は、Ⅵm・Ⅵm7 に、借用の Ⅵ♭M7 を加えた**（Ⅴ7→Ⅵ♭M7 は、短調での偽終止）。Ⅵ♭M7 を外すこともできる。
5. **固有進行は「→」のつなぎ目を無視する**（Ⅵm → Ⅳ Ⅴ も小室進行）。厳密に「4つの位置ぴったり」にしたいなら、変えられる（ただし、ブルース進行の Ⅳ「→」だけは、2つの形で対応している）。
6. **カノン進行は、1番からだけ**にした（5つ・8つの並びで、5番からでは盤に入らないため）。「弱進行」の変形のまま、図鑑では「弱進行」に数える。
7. **Ⅴ→Ⅰ は「Ⅴ-Ⅰ終止」（200点）にして、「強進行」とは数えない。** ただし、**終止にならない場所（フレーズの途中）の Ⅴ→Ⅰ は、「強進行」**（100点）になる。
8. **ピカルディ終止（2026-11-18 に、ご指摘で作り直した）= 「Ⅵm で終わるところを、長三和音の Ⅵ で終える」。** 以前の「短調の響きの駒 → Ⅰ」は誤りだった（Ⅳm7 → Ⅰ は、サブドミナントマイナーから Ⅰ へ着地する技で、ピカルディ終止ではない）。盤の主音は長調の Ⅰ なので、短調の主和音は **Ⅵm（イ短調）**。直前の和音は、イ短調の終止に向かうもの（Ⅲ7・Ⅴ・Ⅱm・Ⅵm・Ⅵsus4）にした。資料と、直前の和音の表は [theory_audit.md](theory_audit.md) の5章。Ⅵ（長三和音）と Ⅵsus4 は、**新しい駒**（ID 30・31）。
9. **Ⅲ は Ⅲm・Ⅲm7・Ⅲ7 のどれでも**、王道進行・Ⅳ-Ⅲ-Ⅵ進行にする（資料によって、Ⅲ7 の王道もあるため）。
10. **（2026-11-18に変更）盤のループのつなぎ目（8番 → 1番）は、進行系の技だけ数える。** 「8小節目から1小節目に、ドミナントモーションなどの進行系のテクニックが成立している場合も加点してください」というご指示を、「**8番の駒 → 1番の駒（休みがない）**の、ドミナントモーション・弱進行・半音下（裏コード・セカンダリードミナント・ツーファイブワンを含む）」と読んだ。終止（フレーズの終わりで成立）と固有進行（1番・5番から）は、つなぎ目をまたがない。

## 9. まだ作っていないこと・限界

- キーは**いつも長調（Ⅰ = 主音）** として見る。Am を主和音にして作った短調の進行は、度数がずれて見える（Ⅵm が主役になる）。
- 駒の表にない和音（♭Ⅶ・♭Ⅵ の長三和音、Ⅳ7、分数コードなど）を使う進行は、作れない（[progression_catalog.md](progression_catalog.md) の3章）。
- 技の判定は、**和音の並びだけ**。リズム・テンポ・ドラムのパターンは、点に入っていない。
- 対戦モードは、まだない。
- 同じコードのタグを2枚登録すること（カノン進行は Ⅰ・Ⅳ・Ⅴ を2回使う）は、実機で未確認（理屈の上では、タグごとに登録するので、できる）。
