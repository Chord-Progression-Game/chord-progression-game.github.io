# チャレンジステージ・タイムアタックの仕様（2026-11-23）

> 画面の名前を変えました。**「チャレンジ」（90秒の得点競争）→「タイムアタック」**。新しく、**「チャレンジステージ」**（ステージごとに条件が課され、その条件を守ったまま、ノルマの得点をめざすモード）を作りました。
> 内部の名前は、タイムアタック = `challenge`（保存ずみの記録 `save.best.challenge` を、そのまま使うため、変えていません）/ チャレンジステージ = `trial`。

## 1. メインメニューの並び（ユーザーの指定）

| 順 | 画面の名前 | 何をするか | 内部 |
|---|---|---|---|
| 1 | チュートリアル | 技をひとつずつ覚える（続きから） | `tutorial` |
| 2 | チュートリアルを選ぶ | 好きな技から練習する（もとの「ステージを選ぶ」） | `showStages()` |
| 3 | メロディーにコードをつける | 流れるメロディーに和音を合わせる（もとの「合わせる」） | `melody` |
| 4 | **チャレンジステージ** | 条件を守って、ノルマの得点をめざす | `trial` |
| 5 | フリープレイ | 全部の駒で自由に | `free` |
| 6 | **タイムアタック** | 90秒で高得点を狙う | `challenge` |
| 7 | 対戦 | 準備中 | — |

「チュートリアルを選ぶ」の画面には、チュートリアルのカードだけが並びます（フリープレイ・メロディー・チャレンジの入り口は、タイトルのメニューから）。ゲーム中の MENU の「選ぶ」ボタンは、いまのモードに合わせて「チュートリアルを選ぶ」「チャレンジステージを選ぶ」「メロディーを選ぶ」になります（フリープレイ・タイムアタックには、選ぶ画面がないので、出ません）。

## 2. チャレンジステージのしくみ

- **条件（rules）**: ステージごとに、データで書いてあります（`game/js/game/trials.js`）。盤の駒と、判定の結果から、いま守れているかを、いつも調べます（`evaluateTrial`）。左のガイドの欄に、条件の一覧（守れているものに ✓。守れていないものは、いまの様子つき）と、ノルマ（「ノルマ 400点 / いま 680点」）が出ます。上のバー（PC）・上の細い帯（スマホ）にも、「条件 3/4 ・ 得点 420 / ノルマ 800」と出ます。
- **使える駒（pieces）**: そのステージで使える駒だけが、トレイに並びます（制限のないステージは、全部）。実機の盤では、駒を制限できないので、「使える駒だけを使う」という条件としても調べます。
- **クリア**: 条件が**全部そろって**、得点が**ノルマ以上**になると、「できた！ 提出する」ボタンが押せます。押すと、結果の画面（星・得点・条件の一覧・決まった技）が出て、記録（`save.trial[ステージ id] = { best, stars, at }`）が残ります。
- **星**: ノルマ以上 = ★1 / ノルマの 1.4倍 = ★2 / 1.8倍 = ★3。
- **解放**: 最初のステージだけ開いています。前のステージを提出すると、次が開きます（「ぜんぶ開く（デモ用）」でも開く）。
- **ヒント**: 使えます（トレイの駒だけが候補になります）。プリセット・メロディの画面は、使えません。
- 提出したあとに、「盤面を見る・編集する」で、盤面を直し続けられます（記録は、提出したときのまま。もう一度提出すると、ベストが上がれば、更新）。

## 3. 条件の種類

| 種類 | 書き方 | 意味 |
|---|---|---|
| 技 | `{ type: 'kind', kind, variant?, min }` | その技を、min 回以上 決める（variant があれば、その形だけ） |
| 仲間 | `{ type: 'group', group, min }` | つながり（motion）・終止（cadence）・名前のついた進行（named）・借用和音（borrowed）の技を、min 回以上 |
| 種類数 | `{ type: 'kinds', min }` | ちがう種類の技を、min 種類以上 |
| コンボ | `{ type: 'combo', min }` | 技を、min 個以上、つなげる |
| ジャッジ | `{ type: 'sense', min }` | ジャッジの加点（耳に馴染む並び・なめらかな声・内声）の合計が、min 点以上 |
| 使える駒 | `{ type: 'only', names }` | 使える駒は、これだけ |
| 使う駒 | `{ type: 'use', names }` | これらの駒を、ぜんぶ使う |
| レベル | `{ type: 'level', min }` | Lv. が min 以上の駒を、1つ以上使う |
| 駒の数 | `{ type: 'max', n }` / `{ type: 'min', n }` | 駒（「→」を含む。分割したマスは、前半・後半を 1つずつ数える）が n 以下 / n 以上 |
| 場所 | `{ type: 'fill' }` | 8つの場所を、ぜんぶ使う（分割したマスも、1か所） |
| 重なり | `{ type: 'noDup' }` / `{ type: 'maxSame', n }` | 同じ駒を、2回使わない / n 回まで |
| 禁止 | `{ type: 'ban', kind }` | その技は、使わない |
| 指定 | `{ type: 'at', slot, names }` | slot 番目（0 から）は、この駒のどれか（分割したマスは、前半） |
| 「？」 | `{ type: 'noOddity' }` | 冒頭のドミナント（？）を出さない |

## 5. タイムアタックの変更

- 名前: 「チャレンジ」→「タイムアタック」（タイトルのメニュー・見出し「TIME ATTACK」・結果の「タイムアタック」・操作の欄「⏱ タイムアタック終了」）。
- 結果の画面のボタンは、「もう一度」「盤面を見る・編集する」「タイトルへ」の3つ（選ぶ画面は、ありません）。
- 中身（90秒・得点は盤の得点の最高値・星 500 / 1000 / 1800）は、変えていません。

## 6. 確かめたこと / まだ確かめていないこと

- 確かめた（自動テスト）: 9ステージの定義・お手本の盤が、条件とノルマを満たす・ゲームの流れ（読み込み → 置く → 条件の知らせ → 提出 → 記録 → 次が開く）・画面（選ぶ画面・条件の一覧・提出ボタン・結果）を、本物のブラウザで。
- まだ: **遊んでみたときの、難しさ・ノルマの妥当性**（ご自身で）/ 実機の盤（本物の駒）で遊んだときの手応え / スマホの実機。
